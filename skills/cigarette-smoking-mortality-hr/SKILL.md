# 卷烟吸烟分档死亡 HR

读取 Li 等发表于 Circulation（2018）的正文 Table 2 和补充 eTable 1。
使用对象是有卷烟吸烟史资料的成年人，数据类型为问卷。报告引用美国队列关联，不能当成中国人群的风险校准模型。

```bash
python3 scripts/personal_report.py --measurements smoking.csv --smoking-status current --out out
```

`smoking.csv` 的表头为 `marker,value,unit`，例如一行 `cigarettes_per_day,15,1`。
输入是每日**卷烟支数**的整数计数（单位 `1`），不是包/天、包年或终生支数。
识别别名包括「每日卷烟支数」「每天吸烟支数」「cigarettes/day」。不假设每包的支数。

`--smoking-status` 必须明确为 `never`（从未吸烟）、`past`（既往吸烟、现在不吸烟）或 `current`（目前吸烟）；也接受「从未吸烟」「已戒烟」「目前吸烟」。
当前吸烟者每日支数必填且至少一支；从未或既往吸烟者可不提供测量文件，若提供支数必须为零。
无法仅凭零支判定是从未吸烟还是已经戒烟。偶尔吸烟、非整数日均支数或非卷烟使用情况不做猜测映射。

`--age`、`--sex` 为可选背景，不改变合并 HR，也不按当前年龄自动切换分析。
研究原始招募年龄是女性 30–55 岁、男性 40–75 岁，女性分析从招募后开始；不要把这些招募年龄当成个人模型的有效区间。

若用户已提出每日支数目标，可传 `--targets targets.csv`，列名与测量表相同。仅支持目前吸烟者的每日支数目标。
零支目标对应既往吸烟组；吸烟史不能重置为从未吸烟。这是另一组的关联对照，不是个人风险会下降多少或何时下降的预测。
`levers.json` 的敏感度列表为空，因为该方法是分档表，没有连续斜率；目标差值仅指表内 HR 的算术差。

输出 `report.md`、`result.json`、`levers.json`；缺项、单位错误、矛盾状态、未知项目或超范围时退出码为 3，写 `problems.json`，不留下本次或旧的计算结果。
参考组没有印出置信区间，其上下限输出 `null`，不能伪造为 1–1。

无需联网即可运行。禁止让用户提供论文、NHANES、CDC 数据、补充材料或研究队列；查表常数已冻在 `scripts/presets.py`。
完整生活方式总分需要队列饮食分位数切点，本文正文及补充材料没有给出可直接给个人使用的切点；本技能只实现吸烟部分，不补全缺失模型。

每份报告先放论文卡片，随后是个人分档及对应队列结果。保留以下边界原文，不给药物剂量或启停建议：

> 边界：这里只按你的卷烟吸烟史匹配观察性队列分组；HR 是该组相对从未吸烟组的关联，不是个人死亡概率、剩余寿命或改变吸烟后的因果收益，不能据此开始或停用药物。
