# 论文说法与技能实现

- 研究设计：横断面诊断准确性研究（同一次神经心理评估里比较认知健康组和轻度认知障碍组；期刊栏目 ORIGINAL ARTICLE，Crossref 类型 journal-article；PubMed 出版类型未核对）。
- 全部样本组：意大利南部普利亚大区经老年活动中心和社区招募的 136 名成年志愿者（女性 77 人，平均 63.37 ± 9.71 岁，受教育 11.85 ± 4.51 年）；认知健康 72 人，轻度认知障碍 64 人（表 1）。表 4 的 ROC 按表中百分比推算用了 72 名认知健康者和 60 名轻度认知障碍者（共 132 人），论文没有说明另 4 人为何不在。没有单独的验证队列。
- 物种：人（Homo sapiens）。
- 利益冲突：作者声明研究中没有任何可能构成利益冲突的商业或经济关系；研究没有专项资助。ItFNAT 由本文作者（Manippa 等）开发和建立常模。
