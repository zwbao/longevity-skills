# 睡眠时长风险查表

用户命令：把我的通常睡眠时长按论文查表，列出死亡和心血管事件的人群相对风险；如果我提供目标时长，也比较对应的查表结果。

用户只提供自己的通常睡眠时长，不索要论文、补充表或公开队列。使用一般健康成人的习惯性睡眠信息，不把单晚记录或卧床时间当作长期睡眠时长。

准备 CSV，列为 `item,value,unit`。例如 `sleep_duration_h,9,h`，或 `睡眠时长,540,min`。单位支持 `h`、`min` 及 skillkit 的小时、分钟别名；标准键省略单位时按小时读。

```bash
python3 scripts/personal_report.py --measurements measurements.csv --out out
```

可选 `--targets targets.csv`，目标表使用相同列名，只有睡眠时长一个目标输入。可选 `--age`、`--sex male|female` 是背景接口，不改变总体查表值。

- 正文表 2 印出 3–11 小时的整数点，严格匹配，不四舍五入、不插值、不外推。非整数值真实有效但本方法不支持，不能要求用户改成整数来得到结果。
- 3 小时缺冠心病和卒中；11 小时只有全因死亡；7 小时参照点未印置信区间。保留空值，不用 1 或 0 补齐。
- 研究混合夜间与全天睡眠、问卷与访谈，未单独校准手环数据；不声称对某年龄、性别或地区已个体化。
- 输出 `out/report.md`、`out/result.json` 和 `out/levers.json`。levers 中敏感度是相邻已印出小时点的 RR 差，目标情景是另一查表点；都不是因果获益。
- 输入缺项、单位错误、超范围、非整数或表外输入返回退出码 3，输出 `out/problems.json`，报告保留论文卡片和边界，数值结果全部为空。

报告必须从论文卡片开始，然后说明个人输入对应的是研究人群 RR。心血管结局混合发病与死亡，不能把 RR 写成发病概率、寿命或个人健康评分；置信区间不是个人预测区间。不推荐目标时长，不给药物剂量，不给开始或停止药物的指令。

每份报告必须原样保留：

边界: 这是前瞻性队列荟萃分析中的人群关联，不是个人发病或死亡概率，也不证明改变睡眠会降低风险；不能据此决定开始或停止用药。
