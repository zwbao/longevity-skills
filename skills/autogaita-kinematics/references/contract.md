# 产品合同与可行性

1. 用户提供自己的一个完整、等间隔、侧面地面步行周期的时间戳与髋、膝、踝、足中部二维坐标；坐标已标定到物理长度，且行进为 x 正方向。
2. 技能运行时不下载公开数据；方法定义已由正式正文、全部附件及公开代码核对，群组统计和 MoVi 不是个人测量的替代品。
3. 报告计算该周期的膝踝内角极值、各标志点水平速度峰值、足中部实测跨步距离及到达最大横坐标的时间；不输出推进力、回归预测跨步距离、PCA 评分、年龄判断或临床风险。

流水线已授权实现个人读出；本合同不额外引入确认步骤。

## 定义与来源

来源为 Hosseini 等，PNAS 123(35), e2534093123 (2026)，DOI 10.1073/pnas.2534093123。

| 计算 | 完整定义 | 核对位置 |
|---|---|---|
| 内角 | 以关节为顶点，两相邻标志点向量点积除以模长积，反余弦转为度；膝由髋—膝—踝，踝由膝—踝—足中部定义 | Fig. 2F、SI Fig. S2C；v1.3.1 `resources/utils.py::compute_angle`、`common2D_3_analysis.py::add_angles` |
| 水平速度 | 原始 x 序列的中心差分，两端为单边差分；先计算速度再归一化 | v1.3.1 `common2D_3_analysis.py::add_x_velocities`、`analyse_and_export_stepcycles` |
| 速度单位 | 原代码以每帧位移输出，图轴写每个采样间隔；本实现除以实测等间隔 dt，显示 cm/s | `common2D_4_plots.py::plot_x_velocities_by_average_SC`；主文 Human Dataset 的采样设置 |
| 周期归一化 | 默认 25 箱；缩短时连续分组取均值，余数分配给前面的箱；延长时等间隔选取源索引重复 | 正文 Methods: Normalization of Segmented Data；v1.3.1 `common2D_3_analysis.py::define_bins` |
| 曲线横坐标标准化 | 每个周期全部关节的 x 减去本周期足中部 x 最小值 | SI Appendix p.3，Standardisation of horizontal coordinates；参考标志点固定为足中部 |
| 实测跨步距离 | 足中部 x 最大值减去周期首帧足中部 x | SI Appendix p.5，Kinematic Propulsive Strength |
| 到最大位置的时间 | 最大足中部 x 对应时间戳减去首帧时间戳；并非整个周期时长 | SI Appendix p.5 的 stride duration 定义 |

全部纳入计算的定义都已公开，无训练权重、截距、拟合系数或临床切点。
速度峰值是**归一化后单周期的有符号水平速度最大值**；没有取向量模长。
角度极值和跨步距离取自**归一化前**的周期，避免分箱均值改变极值。
原始周期以人工标注的首次离地帧开始，以再次离地前最后一帧结束；脚本不能仅凭坐标证明周期标注正确。
此单周期入口不自动合并左右腿或多个周期。论文群组曲线是跨周期、试次和受试者的平均，不能与本输出逐数当作同一种统计量。

## 明确不实现的计算

附录 p.6 的人体回归报道踝推蹬与髋振荡的两个系数，但未在已检查材料中给出完整的截距及时间协变量系数。
Datasets S1–S38 是 PCA 与群组统计，S39 是人体年龄、身高、性别；它们不是完整的推蹬回归参数表。
公开 AutoGaitA v1.3.1 核心代码实现通用运动学处理，不能用它补出缺失的论文专用回归参数。
因此这里不调用、不近似、不重新拟合该回归，也不把实测跨步距离说成预测跨步距离。
附录人体推蹬斜率的印刷式分母使用 `x(max(angle))−x(min(angle))`；未核清所指自变量前，不将其自行改写成时间差或指定某关节横坐标。
这些排除项不是本合同输出所需的参数，不以它们阻止已完整定义的直接运动学测量。

## 验证与实现选择

先写 `tests/test_manifest.py::test_printed_normalization_index_mapping`，再写实现。
正文示例给出 5 个源时间点归一化到 10 箱时的索引重复序列。测试只验证这个映射；
它不是一位受试者的角度、速度或跨步距离算例，所以 `validation.status=draft`。
遍查正文、附录与图、39 张表、Movie S1 和代码示例，未找到完整人体坐标与相应印刷结果。
图轴刻度、PCA 方差和群组显著性均不冒充个人输出的期望值，也不从图上读点拟合参数。
其他测试使用明确标注的合成几何，检查单位换算、整体平移不变性、结果结构及错误阻断；
不声称合成数据是论文示例，不把程序自产数字写成金标准。

输入坐标范围 −1000 至 1000 cm、时间戳 0 至 86400 s 和年龄 18 至 120 岁是接口防错范围，
不是论文参考区间或临床阈值。相邻时间戳差须为 0.0001–1 s（接口覆盖采样间隔），
等间隔判定使用相对容差 1e−6、绝对容差 1e−9 s，只用于浮点表示误差。
至少三帧是差分的接口下限，不能替代完整周期要求。
反余弦输入仅对浮点误差钳制到 [−1,1]；相邻点重合直接报错，不补坐标。
不平滑、插值、推断周期边界或从置信度筛帧。提供方需先核对追踪。
角度的度数转换为数学单位转换，不是经验常数；长度和时间换算只经 skillkit 的清单因子完成。

中文报告首先由 `paper_card.py` 渲染论文卡片，成功与失败报告都保留同一句边界。
本方法没有可干预的风险函数，因此没有 `--targets` 和 `levers.json`。
