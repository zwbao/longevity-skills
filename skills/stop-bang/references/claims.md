# 证据核对：Chung 等，Anesthesiology，2008

研究设计：人体筛查方法开发、重测可靠性与前瞻性招募的诊断准确性验证，
以术前多导睡眠监测为参照；不是随机干预试验。Europe PMC/PubMed出版类型为期刊原创研究，非综述。
技能evidence为method。

全部样本组（pp.813–817、Figure 1、Tables 1、3–5）：

- 加拿大Toronto Western Hospital与Mount Sinai Hospital成人术前门诊，年龄至少18岁，ASA I–IV，拟行择期手术。
  排除已诊断OSA或其他睡眠呼吸障碍、无法/不愿同意，以及预计脑电异常者；讨论段称本工具仅在非癌症手术患者中验证。
- 2974人愿意答题，2721人完整回答并有性别、年龄、BMI记录。
  因子分析问卷发给278人，254人完整作答；其后STOP试点592人、验证1875人，共2467人。
- 2467人中2051人未同意PSG；416人同意，其中205人未到场、211人完成PSG。
  前34人为试点，后177人为验证；这些阶段不是独立人口总数相加后的新队列。
- 另55人参加重测；其中53人两次分数相同，属于可靠性分析，不额外加到总体人数。
- 验证177人中STOP低风险75人、高风险102人；按AHI分组，AHI≤5有55人，AHI>5有122人。
  后者轻度52、中度31、重度39人；这是同一验证样本的不同切分，没有独立健康对照招募。
- 试点AHI>5人数存在原文冲突：Figure 1印25人，而p.815 Pilot Study段印24人。
  本技能不由这些汇总数重建逐人数据或性能，不静默改正任一数。

物种：人（human；Homo sapiens）。本文无动物或细胞实验。

读表记录：Table 1列Total、Factor Analysis、No Consent、Consented No Polysomnography、Polysomnography Done；
Table 2列题项与Factor Loadings；Table 3列Total与STOP Low/High Risk；
Table 4按AHI≤5和>5列人口学/临床变量；Table 5增加Total并列睡眠参数；
Tables 6、7分别按AHI>5、>15、>30列敏感度、特异度、PPV、NPV、似然比、比值比与ROC面积。
两个附录均为文内材料，题干后为Yes/No选择，结尾为分类规则。

其他原文差异：摘要及Table 3总AHI印20±6，Table 5则印19.5±22.9；
只记录差异，不选择其中一个作为个人报告指标。讨论中STOP-Bang性能处引用table 6，
而相应数据实际位于Table 7；本技能以表题识别，不将两表互换。

局限：PSG拒绝和未到场较多，有自我选择偏倚；跨普通人群外推有限。
