# 产品合同

用户提供自己的四项STOP回答、BMI和实测颈围，以及实足年龄和原问卷性别项。
技能使用已经核对的2008年文内附录规则，运行时无需公开数据下载，也不要求用户找论文或研究数据。
报告只输出八个肯定项计数、两套总分和原版高低风险分类，不输出AHI、严重程度、个人患病概率、手术安全结论或药物决策。

## 常数出处与操作定义

| 计算所需内容 | 原文定位 | 实现 |
| --- | --- | --- |
| 打鼾、白天疲倦、目击呼吸暂停、高血压或治疗四项 | p.813；p.821 Appendix 1 | 是计一个肯定项，否不计；未知拒绝 |
| STOP高风险至少两个肯定回答 | p.815 Pilot Study；p.821 Appendix 1 | 总数>=2，否则低风险 |
| BMI严格大于35 kg/m² | p.821 Appendix 2，第5项 | 独立比较，不含等号 |
| 年龄严格大于50岁 | 同页，第6项 | 独立比较，不含等号 |
| 颈围严格大于40 cm | 同页，第7项 | 不区分男女阈值，不含等号 |
| 男性项 | 同页，第8项 | 男性肯定；未知不可推断 |
| STOP-Bang高风险至少三个肯定回答 | 同页，附录2结尾 | 八项计数>=3，否则低风险 |

这是计数，不存在需要拟合或重建的系数；Tables 2的因子载荷不是个人评分权重。
连续输入都保留原始精度，比较前不取整。年龄接受小数岁；若只有整数年龄，按用户提供的岁数计算。
问题中文为释义，不声称为经验证的中文问卷。未新增血压数值阈值来代替高血压病史题。
BMI取用户已知值；未另加身高体重计算器。颈围采用实测，不推算衣领码。

BMI 10–100、颈围15–80 cm、年龄上限120岁是技术防错范围，不是论文发表的验证区间。
年龄下限18岁来自纳入标准，实际样本最大年龄未打印，故不虚构population年龄范围。
颈围接受mm×0.1、m×100、in×2.54换为cm，因素来自仓库单位标准。
CLI同时输出两套评分，任意必需项缺失均退出3；每次运行清理旧结果，失败不保留上次分数。
问卷是分类筛查，不提供通过改体型或回答来设定目标的模型，故没有targets/levers接口。

## 验证合同

先检查了Tables 1–7、Figures 1–2和Appendices 1–2，未找到个人回答/测量值与总分配对实例，
也未找到逐项数值加总的已填写问卷。表6、7是队列敏感度、特异度等汇总统计；
图2的数字是特征亚组的阳性预测值，不能作为某个人的概率，也无法从一个问卷重算。
缺少逐人数据，不能声称复现队列性能。

严格保留`validation.status=draft`与`inputs_status=draft`，不将规则测试伪装成论文个人实例复现。
