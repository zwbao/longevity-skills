# 产品合同与计算来源

1. 用户提供本人已满周岁年龄、论文使用的性别分类、BMI及八项自报健康信息；由助手先确认社区居住、可自行回答且无痴呆的适用情境。脚本检查十一项输入完整性，不能把缺项当无风险。
2. 技能使用已经核对并冻结在 `scripts/presets.py` 的表2积分、表3验证队列分档风险以及内嵌附录的问题定义；不需要用户寻找论文或NHIS数据，也不在运行时下载或重新拟合。
3. 报告仅给逐项分、总分、同分档五年风险及该档人群风险的95%置信区间，并允许用户指定的非因果情景比较；不计算个人剩余寿命、治疗收益或未公开的连续Cox绝对风险。

本任务由流水线明确授权完成，按用户要求直接落实合同，无需额外确认。

## 可行性和参数合同

| 位置 | 已核对的列/内容 | 在技能中的用途 |
|---|---|---|
| Table 1 | Weighted % with characteristic；Hazard ratio (95% confidence interval) | 研究背景，不作为个人计分系数 |
| Table 2 | 风险因素与类别；Adjusted HR (95% CI)；Points | 只用Points列，不用四舍五入的HR反推系数 |
| Table 3 | Development与Validation各自的n、Mortality 5-year % (95% confidence interval)、Person-year rate (%) | 只用Point score部分Validation的五年风险及CI，不用人年率，不用缺少分数边界的quintile部分 |
| Appendix | 原始问题、类别、积分 | 确定年龄、疾病、功能、吸烟和住院的操作定义 |
| Discussion | 两个80岁女性示例 | 先写测试，然后实现计分；不复现文中的筛查建议 |

积分按表2相加。年龄和BMI阈值、二分类/三分类权重、住院分组及全部风险档位统一保存在presets.py；没有拟合或补造常数。表3对18分及以上合并，程序沿用合并档，不外推或插值；置信区间是同档估计的不确定性，不是个人预测区间。只有整数积分查表，因此不需要Cox截距或基线生存函数。

原文摘要/方法文字有 `>85` 与 `>2`，但表2及附录明确85+和住院two or more；实现采用包括85岁、包括2次的边界。Methods、标题和附录为65岁及以上，故接受65岁。肺病合并的是曾被专业人员告知的肺气肿或慢性支气管炎；糖尿病包含原问卷borderline，不自行把血糖值或所有糖尿病前期标签代换进去。癌症排除非黑色素瘤皮肤癌；IADL使用是否需帮助而非某量表总分；步行问题要求独自且不用辅助设备，不能走/不走也计为困难。

输入编码0/1/2只是本实现接口，非NHIS数据字典的原始编码。年龄65–120、BMI10–80、住院次数0–365是接口合理性检查；120、10、80、365不是论文新系数或研究年龄/BMI上限。论文未报告最高年龄，故不声称这些界限覆盖了全部验证年龄。BMI的kg/m2与kg/m^2是同一单位，因子精确为1；其他单位不猜测换算。

## 复现

首先写入 `tests/test_manifest.py` 的两个Discussion病例以及表2/表3测试。无其他风险因素的80岁女性应得5分、查表8%。测试以BMI=25代表原文无低BMI风险的参考类别；这不是声称论文印出了该女性的具体BMI。其他参考类别为自评极好/很好、无指定疾病、独立活动、无步行困难、从未吸烟、无过夜住院。第二病例为80岁女性、既往吸烟、有COPD和糖尿病、购物需帮助、步行困难、自评一般，原文17分且五年风险超过50%；再独立核对表3验证队列16–17分档55%（48–62%）。未用这些输出反推任何常数。

表2所有类别和年龄边界、表3验证列全部十档均逐项精确核对。验证状态reproduced仅表示印出病例/积分/查表可复现，不表示重新完成队列统计验证。表3推导队列14–15分档印为47 (32–42)，区间不包含点估计；原样记录此疑点，不猜测更正，也不使用该列。

## 情景输出

`--targets`沿用输入列和单位，允许BMI、自评健康、IADL帮助、步行、吸烟状态和过夜住院次数；年龄/性别/既往诊断固定。既往或目前吸烟者不能以从未吸烟为目标。改变过去一年住院次数只代表另一观察窗的假设，不改写病史。所有改变都是查表对照，不提供目标建议或因果降风险承诺。

`longevity-levers/1`的current保留当前结果，sensitivity列出每项其他评分档位替换的积分及风险差（百分点），levers列出指定目标逐项替换，targets列出全部目标一起替换。阶梯函数不存在全局平滑导数，因此明确标记discrete_category_contrast，不输出误导性的连续斜率。不可逆因素的档位对照也标target_allowed=false。

边界：这是美国社区居住、可自报健康状况且无已报告痴呆的65岁及以上人群的历史队列分档估计，不是个人剩余寿命或因果干预效果；不适用于养老机构居民或痴呆患者，不能据此开始或停止药物、筛查或其他治疗。
