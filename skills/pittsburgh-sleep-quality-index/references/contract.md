# 产品合同与可计算范围

1. 用户提供过去一个月已填写 PSQI 的个人回答：通常上床和起床时刻、入睡所需分钟、实际睡眠小时、Q5a–Q5j 及 Q6–Q9 的原选项编码。Q10 的同伴情况及同伴评价不计分。输入是问卷（questionnaire），不是手环测量；不得用一夜或一周替换一个月。
2. 技能已核对 Buysse 等 1989 年原论文全文及文内附录，运行时不联网、不索要论文、补充表或队列。公式及映射保存在 presets.py。原论文及官方表单不复制进仓库。
3. 报告给出七个分量、总分与是否严格大于 5，以及计算用卧床时长和睡眠效率。只处理印刷规则唯一覆盖的回答；原文歧义值返回问题，不生成总分。不估计生物年龄、寿命、死亡风险、诊断或治疗效应。

流水线用户已授权完整实现，无需再次确认合同。

## 公式来源与适用域

| 计算 | 原文定位 | 采用的印刷规则 |
|---|---|---|
| 主观质量 | p.211 Component 1 | Q6 的四档对应 0、1、2、3 |
| 入睡潜伏期 | p.211 Component 2 | Q2 ≤15 / 16–30 / 31–60 / >60 分钟，对应 0/1/2/3；加 Q5a 后按 0 / 1–2 / 3–4 / 5–6 对应 0/1/2/3 |
| 睡眠时长 | p.211 Component 3 | >7 / 6–7 / 5–6 / <5 小时，对应 0/1/2/3；恰好 6 同时落入两行，拒绝自动赋分 |
| 睡眠效率 | p.212 Component 4 | 实睡小时÷卧床小时×100；>85 / 75–84 / 65–74 / <65%，对应 0/1/2/3 |
| 睡眠障碍 | p.212 Component 5 | Q5b–Q5j 九项之和 0 / 1–9 / 10–18 / 19–27，对应 0/1/2/3；不包括 Q5a |
| 助眠药使用 | p.212 Component 6 | Q7 四档对应 0/1/2/3；仅描述过去频度 |
| 日间功能 | p.213 Component 7 | Q8+Q9 后按与潜伏期相同的和数表转换 |
| 总分 | pp.211,213 | 七个分量等权相加，0–21 |
| 筛查切点 | p.199 Validity、p.202 Fig.2、p.205 | 严格 >5 为论文较差睡眠筛查侧；≤5 仅为未超过切点，不保证没有睡眠疾病 |

数字常数均在上述位置。技术性换算 60 分钟/小时、1440 分钟/天不是研究系数。时刻输入为自午夜起分钟；取起床发生在上床后的下一次时刻，支持跨午夜，不支持跨多日或上床/起床时刻相同。Decimal 运算避免浮点误差把恰好 85% 分入 >85%。不对效率四舍五入。

## 原文空档及后续版本

原版 6 小时重叠、效率 (74,75) 与 (84,85] 未覆盖。Q2 要求整数分钟，避免 (15,16)、(30,31) 的未定义小数区间。原文没有印舍入规则，本实现不补充。遇到上述值退出 3，问题类型为 source_ambiguity，明确这是来源不足，不暗示用户更改真实回答；需要计分人员核对版本和规则后另行评分。实际睡眠超过卧床时间、入睡所需时间超过卧床时间、时刻相同均拒绝，不截断到 100%。范围是工程防错界限，不是临床正常范围。

官方现行 Exhibit A 提到 2005-05-20 对 Q5j 缺失或缺说明文字时置 0 的修改，其文字中的若干不等式仍漏等号。这里保持原论文要求完整回答的范围，Q5j 必填；没有其他原因须明确填 0，不把空白当 0。中文字段标签只是输入映射，不是新翻译或重新验证的问卷。英文问卷和中文授权版本从官方/MAPI取得；保留既有问卷的选项，不重新设计量表。

PSQI 是描述性问卷评分，不是可作因果干预模拟的风险方程或年龄模型。不给 --targets 或药物项优化建议，不提供 levers.json。

## 复现

先写 tests/test_manifest.py::test_appendix_disturbance_scores，再实现计算。该测试枚举 p.212 Component 5 表中所有和数，期望分数直接来自对应印刷单元格，整数完全相等。另测 pp.211–213 的潜伏期、时长、效率及两项和映射。端到端用明确标注的人造问卷覆盖 p.211 的全无困难 0 和各领域严重困难 21 两个印刷端点；不是论文参与者，也不是独立验证队列。未使用 Table 3 群体均值反推个体输入、未重建敏感度或特异度。

## 固定边界句

边界: 本结果只描述过去一个月的自评睡眠质量，不能诊断失眠或其他疾病，不能换算生物年龄、寿命或死亡风险；不能据此开始、调整或停止药物。
