# 产品合同

1. 用户提供自己的提物、室内步行、从椅子或床起身、上楼困难程度及过去一年跌倒次数；年龄、性别可选。
2. 技能已从期刊与PMC全文核对并固化规则，运行不取外部数据，不向用户索要论文或队列。
3. 报告只算五项得分、总分及筛查分档，不作诊断、不估计个人死亡概率、寿命或治疗收益。

流水线已授权直接实现此个人读出。来源：Malmstrom 等，2016，DOI 10.1002/jcsm.12048。

## 可行性与取舍

动手前已打开出版社文章页、PMC全文以及Europe PMC全文XML，并核对五张正文表。
没有列出独立补充材料、附录、eMethods或配套GitHub/Zenodo/OSF代码与数据发布链接。
正文提及NHANES公开调查，但没有发布本研究可复现分析包；个人评分不依赖调查微数据。
FRAX网页是讨论中的类比工具，不是本评分依赖。全文未复制进仓库。

所有计算常数均位于 Methods 的 SARC-F questionnaire (0–10 points) 小节：

| 输入或运算 | 规则 | 定位 |
| --- | --- | --- |
| 提物困难 | 提举/搬运10磅；无、有些、很困难或不能做分别0、1、2分 | Strength句 |
| 室内步行 | 走过一个房间；无困难0、有些1；很困难、用辅助器具或需人帮助2 | Assistance walking句 |
| 起身 | 从椅子或床转移；无困难0、有些1；很困难、用辅助器具或需人帮助2 | Rise from a chair句 |
| 登阶 | 10级台阶；无、有些、很困难或不能做分别0、1、2分 | Climb stairs句 |
| 跌倒 | 过去一年0次→0分、1–3次→1分、至少4次→2分 | Falls句 |
| 总分 | 五项等权相加，0–10；≥4阳性，0–3阴性 | 小节开头及Results的阳性定义 |

前四项输入为明确回答对应的整数分，跌倒项输入实际次数，由程序换算。
回答分使用score，次数使用1；没有其他可转换单位，因此accept为空，不凭记忆填写LOINC。
10磅约4.54千克仅为题干解释，按国际磅精确换算0.45359237 kg/lb后四舍五入，
该换算不参与评分也不接受重量测量替代自述。计数0–1000、可选年龄18–120为软件防错范围，
不是论文的筛查阈值。超过计数范围需确认输入，不自动截断；缺项、错单位、非整数、非有限数均停止。

只实现AAH/BLSA版本，保留辅助器具及床转移的限定。
NHANES同层房间间步行、无扶手椅起身、平衡/跌倒问题的替代版本另有措辞，不能混用。
中文只作解释性翻译。问卷不是可据以定干预目标的风险方程或时钟；不提供targets/levers。

表2–5提供的是群体比较和关联系数，没有构成完整个人绝对风险预测方程所需的截距、
全部协变量参数及校准信息；本技能不将其中OR或回归系数当成个人结局概率。

## 验证

先写 `tests/test_manifest.py::test_printed_falls_per_term_score`：原文four次跌倒→2分。
逐字短引文在 `skill.json` 的validation中；整数要求完全一致，没有反推或拟合。
其他测试核对正文印出的0次、1–3次对应得分、总分两端0和10、3/4分分档边界。
CLI测试夹具是方法端点组合，不是论文提供的个体病例；不声称复现群体结局分析。
输入错误、别名、缺项与旧结果清除也有测试。

报告始终以论文卡片开头并保留SKILL.md规定的边界句；不输出剂量或启停药建议。

未设置单一population.age_years：AAH给的是更早的入组年龄，BLSA仅给分析年龄下限，
无法从本文得到覆盖所用版本的一个精确闭区间；逐队列年龄保留于论文卡片和claims.md，不拼造上下限。
