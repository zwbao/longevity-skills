# 证据核对

研究为人类观察性验证：AAH与BLSA包含纵向随访和横断面比较，NHANES为横断面分析；不是随机干预或综述。来源与访问记录见[合同](contract.md)。使用2016卷期年，作者Malmstrom等。

全部样本组（Methods / Study sample）：

- AAH：圣路易斯社区非裔美国人，初始2000–01年998人、入组年龄49–65岁；本分析2003–04年Wave 4有853人，2010–11年Wave 10访谈582人，论文称约6年随访。不是三个相互独立的验证样本。表1高分157、低分696。
- BLSA：2003–2012年评估、60岁及以上且五项数据有效的1053人；功能结局随访平均27.07±11.7个月，生命状态最长9.75年。表1高分66、低分987。入组时要求无主要疾病、认知或功能损害，存在健康志愿者选择。
- NHANES：1999–2002全样本21004人，本分析筛出60–85岁且数据完整的3288人；表1高分505、低分2783。为横断面验证，问卷项目有近似替代。

物种：人（human）；未做动物或细胞实验。利益冲突：作者声明无。资助：美国国家老龄研究所R01 AG010436及其院内研究计划。

讨论开头笼统称AAH/BLSA后续6年；Methods细分AAH约6年、BLSA功能随访平均约27个月和最长9.75年的生命状态观察，文档采用分开的定义。AAH随访握力的组间差异未达统计显著，不能写成所有队列、所有结局均一致。作者也指出SARC-F与肌肉量等的相关性有限，其他人群效度、筛查年龄/间隔以及干预改善结局仍需研究。
