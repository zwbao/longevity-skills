# FRAIL 方法合同

1. 用户提供过去四周疲劳频度、独自上楼与步行的困难回答、医生告知的指定疾病种数，以及当前与一年前体重；年龄和性别可选。
2. 技能已从原文 Methods / FRAIL Questionnaire 与 Appendix 1 固定全部计分定义，运行时无须下载公开数据或索要论文附件。
3. 报告只计算五个单项分、总分、问卷分层和体重下降百分比；不输出个人死亡概率、寿命或干预效果。

这是用户授权的流水线实现范围。依据：Morley 等，2012，doi:10.1007/s12603-012-0084-2。

## 可行性与参数出处

在编写实现前已读取出版社文章页、PMC 作者接收稿正文、内嵌 Appendix 1，
以及 NCBI BioC 全文中的 Tables 1–7 和附录表。来源访问记录见 claims.md。
没有发现另列的 Supplementary Tables、eMethods、发布代码或数据附件；
Europe PMC 元数据 hasSuppl=N、hasData=N 与页面核查相符。

| 计算内容 | 印出位置 | 实现 |
| --- | --- | --- |
| 疲劳频度的五个回答编码及阳性回答 | Appendix 1，Fatigue | 原编码1、2计1分，其余3、4、5计0分 |
| 上楼、步行困难 | Appendix 1，Resistance / Ambulation；Methods | 每个是计1分，否计0分；题干分别为连续上10级台阶、步行数百码，独自且不用辅助器具 |
| 指定疾病及种数映射 | Appendix 1，Illnesse | 11类中的0–4类计0分，5–11类计1分 |
| 体重下降百分比 | Appendix 1，Loss of weight | （一年前体重−当前体重）/一年前体重×100；穿衣、不穿鞋 |
| 体重项切点 | Methods，FRAIL Questionnaire | 过去12个月下降至少5%计1分，否则0分；增重保留负百分比 |
| 总分及分档 | Methods，FRAIL Questionnaire | 五项等权各1分；0健壮，1–2衰弱前期，3–5衰弱 |

**正文与附录差异：**正文明确包含体重下降5%的等号，附录仅列大于5%和小于5%，
没有定义恰好5%。采用正文的完整定义，报告每次都提示该差异；不借用其他版本的
半年窗口、不增设“非意愿性”条件、不改变疾病种数的5类切点。
Decimal 用于体重百分比计算，避免常见浮点相减影响恰好处于阈值的输入；不对结果先四舍五入再计分。

## 验证合同

先编写 `tests/test_manifest.py::test_appendix_illness_per_term_scores`，再编写实现。
该测试遍历附录实际印出的疾病计数区间，预期分值0和1直接来自附录的逐项计分，
不是从脚本输出反推。逐字短引文及测试路径在 skill.json 的 validation 中。
没有找到参与者完整输入与对应总分的个案；本技能只声称复现印出的单项得分。
其他测试检验疲劳编码、原文分档、体重阈值两侧、全部二值组合等权求和、单位与错误处理。
这些合成工程用例不冒充论文个案，也不复现队列预测性能。

## 输入处理及边界

- 使用 skillkit 完成文件读取、别名、数值、范围和单位校验；问卷编码及疾病数另外校验整数性。
- 体重统一为kg；lb乘0.45359237，g乘0.001，来自仓库的单位规范，非论文拟合参数。
- 体重15–500 kg和可选年龄18–120岁是工程错误防护范围，不是论文纳入范围或临床切点。
- 非标准键名体重须注明单位，避免把lb当kg；标准键名自身含kg。
- 任一必需项缺失、格式错误、错误单位、越界、非整数编码或矛盾重复值均退出3，写problems.json；不补0、不出部分总分。
- 成功与失败报告均先放论文卡片、末尾保留同一边界句；每次运行清理上次的result.json和problems.json。
- 可选年龄用于提示是否超出研究49–65岁的基线年龄；不加入任何年龄、性别或族群校正系数。
- 没有经过独立验证的中文版本主张；中文题干是本技能的解释性翻译。

Tables 3–5列的是按分层或单项分析的回归关联，缺少完整个人预测模型的截距及
调整变量全系数；没有个人绝对风险计算合同。观察性问卷的历史疾病和功能回答
也不适合作为优化目标，因此不实现 targets/levers，不把“改答案降低得分”解释为降低风险。
