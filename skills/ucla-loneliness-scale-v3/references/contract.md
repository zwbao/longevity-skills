# 产品合同

1. 用户提供 UCLA Loneliness Scale Version 3 完整20题的原始回答编码，使用原题序与原作答选项；年龄、性别可选。
2. 技能已核对 Russell（1996）期刊全文表1并冻结计分常数，运行无需公开数据下载，不向用户要论文、队列数据或补充表。
3. 报告只允许给出逐题得分、总分及分数方向；不提供诊断切点、严重程度分档、常模百分位、因子分数、个人疾病风险或治疗决策。

用户已授权流水线按原文构建技能，按此范围实施，无额外临床决策步骤。

## 可计算性核查（实现前完成）

来源为 Journal of Personality Assessment 66(1):20–40，DOI 10.1207/s15327752jpa6601_2。
已读公开期刊版全文与表1–8，表1使用页面图像校正OCR。检索路径和出版社访问限制见 sources.md。

| 常数或规则 | 原文位置 | 实现 |
| --- | --- | --- |
| 20题，原回答编码1、2、3、4 | 表1，第23页 | 20个必填整数输入，单位score |
| Never、Rarely、Sometimes、Always对应1、2、3、4 | 表1作答说明 | 仅接受该原始编码，最高频度不能改成旧版的Often |
| 星号题1、5、6、9、10、15、16、19、20 | 表1各题前星号 | 逐题反向计分 |
| 原回答1→4、2→3、3→2、4→1 | 表1 Scoring | 明确查表，不拟合或猜测常数 |
| 其他题保留原值，再把所有题得分相加；高分代表较强孤独感 | 表1 Scoring | 等权求和，无额外权重 |

理论总分下上限由20项各1–4分算出；这是推导的算术范围，不是借用其他网站的诊断阈值。
表2的均值、标准差、观察范围等仅用于论文描述，表3的相关系数与表8的因子载荷均不进入个人计算。
第34页脚注说明其他三组的因子载荷需向作者索取；它们不是表1求和所需的参数，不影响本技能可计算性。

## 验证

先写 `tests/test_manifest.py::test_table1_printed_reverse_scores`，再写计分实现。
该测试针对所有星号题，复现原文四组逐项回答—得分映射，逐字引文存于 skill.json 的 validation。
输入及期望输出均来自表1；整数完全一致，无舍入容差、精度反推或第三方拟合。

读完正文、表1–8及脚注，未发现给出完整20项答案与相应个人总分的实例。
`validation.status=reproduced` 仅表示上述逐项得分复现，不能解释为复现队列均值、相关系数或完整患者实例。
CLI测试使用明确标注的合成回答检查同样的逐项映射、求和一致性、错误输入和报告结构；不把合成总分标为论文印出的个人结果。

## 操作边界

- 缺项不插补、短版不折算、总分不倒推；输入小数、非有限数、错误单位或未知题号时停止。
- `score` 为编码单位；没有跨单位转换。中文与英文别名只标识题号，不改变问卷措辞。
- 中文说明用于读懂报告，不是新译制量表。不得宣称本文验证了中文版或所有年龄人群。
- 原文没有统一的回顾时间窗，不另加限制。
- 年龄0–120岁的数值检查仅作输入防错，性别仅作上下文，不是量表系数或经验证的适用范围。
- 无个人诊断切点和疾病风险方程；缺的是此类经过验证的映射，而非表1计分常数。
- 此为自报量表，答题选项不是干预目标或可操纵的治疗因素，因此不提供 `--targets` / `levers.json`。
- 现有 intents.json 没有孤独感或心理社会评估意图；intents暂留空，以mental_social主题和描述触发，不错误归入寿命、认知或化验意图。

边界: 本结果仅描述自报的孤独感，不是精神疾病诊断，不提供轻中重分档、个人疾病风险或寿命预测；不能据此开始、停用或调整药物。
