# 原文证据及范围

研究设计：方法学/心理测量验证原创研究；Europe PMC（PMID 11438246）出版类型为Journal Article，
不是综述。研究1为临床横断面信效度分析；研究2利用失眠随机试验数据验证量表，
不是该试验主要治疗结局的原创报告。故manifest evidence为method。

全部样本组：研究1为145名主诉失眠的临床患者（84女、61男），年龄17–82岁，平均41.4岁。
其中124人有诊断信息：心理生理性45、精神疾病相关36、特发性8、酒精/物质相关6、
疼痛相关12、其他17；这些是145人中的亚组，不是额外样本。
研究2为78名原发性失眠患者，年龄55–84岁，平均65岁；随机分至认知行为治疗、
药物治疗、联合治疗、药物安慰剂四组，本文合并四组分析，未给出各组人数。
表2基线/治疗后/3月/12月/24月样本数为78/71/62/59/57；表6回归样本64，
均属研究2不同分析集，不另计独立验证队列。两研究没有单独的健康睡眠者对照队列。

物种：人（human；Homo sapiens），论文无其他物种实验。

利益冲突：完整正文未见专门Competing interests或Disclosures段，不能记成声明无冲突。
