# 产品合同

用户提供本人记录的总坚果日均可食摄入量，以及明确的比较基准，均为 g/d，可另交自己指定的情景值。
技能使用已核对并冻结在 presets.py 的论文线性增量与 RR，无运行时公开数据下载。
报告只给输入差对应的人群线性关联、区间与数学敏感度，不给个人绝对风险、寿命、非线性预测、摄入目标或药物建议。

本次由 LONGPI_PIPELINE=1 流水线明确授权直接实现，合同作为可审阅文件保存。
数据类型是个人饮食记录/问卷，不是实验或队列统计量。

## 可行性与常数

Aune 等，BMC Medicine 14:207 (2016)，doi:10.1186/s12916-016-0730-3。
实现前已打开出版社全文、Europe PMC 全文 XML、唯一 Additional file 1 PDF 的全部页面文本及目录，视觉核对 PDF 第 41 页的表 S14–S15。
全文没有发布代码或独立数据仓库链接；Availability of data and materials 写明 “No further data are available.”
正文 Table 1、Results 的 Nuts and all-cause mortality 和 Methods 的 Statistical methods 足以确定下面的线性模型。

| 常数 | 来源 | 用途 |
|---|---|---|
| 28 g/d | Methods 的 serving 定义；Table 1 footnote b | 总坚果摄入差的单位增量 |
| 0.78 | Table 1，全因死亡、Total nuts、Dose-response | 已汇总的 RR |
| 0.72、0.84 | 同一单元格 | 95% CI 两端 |

令 Δ=x−reference，`RR(Δ)=exp(log(0.78)*Δ/28)`，区间为
`sort([exp(log(0.72)*Δ/28), exp(log(0.84)*Δ/28)])`。
这只是论文规定的对数线性斜率改写，不是拟合、反推更精细常数或重算随机效应汇总。
负差必须交换区间端点。相对差为 `(RR−1)*100`，不是绝对风险差。
对 x 的 RR 导数是 `RR*log(0.78)/28`，对 reference 是其相反数。
共同情景与逐项情景都调用同一个公式；参考量只是分母的选择，不是干预杠杆。

0–100 g/d 是实现的输入质量检查范围，不是论文切点；100 g/d 也见表 S7 的某个研究暴露档上限，但不能因此声称整个范围均验证过。
仅声明 g/d，accept 为空，不把论文近似的 ounce=28 g 当作精确物理单位换算。
年龄的 18–110 是软件适用性约束，不是研究全体的年龄范围；未提供年龄时由调用者确认是成人。

## 先写的复现测试

tests/test_manifest.py::test_printed_linear_increment 的输入是论文印出的 **摄入差 28 g/d**，不是臆造一个受试者。

仅允许浮点算术误差（RR 1e-12、百分点 1e-10），不声称重现未发表的精细斜率。
测试先于 presets.py 与 personal_report.py 写入。首次运行因系统 Python 无 pytest 未收集；后续使用流水线现有 venv。
这是一项单增量换算复现，不是独立的预测效度验证，也没有复现原始荟萃分析。

## 不能计算的内容

非线性模型需要样条系数、实际节点与协方差；本文只给节点百分位和曲线/部分离散 RR，未提供可直接计算任意输入的完整样条参数。
S14、S15 标题明写 peanuts，正文却用这些表支持总坚果的非线性段落；不能静默改标题或把该表当作总坚果连续公式。
不从曲线读点、拟合插值或强迫线性公式复现 S15 的非线性结果。
不计算绝对死亡概率（缺个人基线风险与统一时间窗），不计算个体改变摄入后的收益（观察性关联不确立因果）。
研究存在异质性、饮食测量误差及残余混杂，线性区间不涵盖这些误差，也不是个人预测区间。
所有情景只保留代数意义，不能据它选出所谓最佳摄入量。
