# 吸烟暴露与疾病相对风险查表

用户命令：`按我的吸烟史，查这篇论文中对应的疾病相对风险。`

先了解用户是否当前吸烟、年龄、性别及想了解的疾病，按 [结局表](references/outcomes.md) 选择 `--outcome`。仅适用于当前吸烟的30岁及以上成人；乳腺癌、宫颈癌只适用于论文女性组，前列腺癌只适用于男性组。心血管结局只支持表2指定参考年龄组，年龄按周岁分组。

## 输入和运行

由助手把真实吸烟史整理为 `marker,value,unit` CSV。不要根据当前每天的量推算过去一生的吸烟量。

- `current_smoker`：当前吸烟填1，单位 `1`。既往吸烟或从不吸烟不能套用本表。
- `equivalent_smoking_years`：每天一包强度折算的累计暴露年数，其数值等于包年数；单位 `a` 或 `year`。这是强度加权的等效年数，**不是普通吸烟持续年数**。需要用户已有的累计包年或完整吸烟史；不能把每日支数直接填入。
- `daily_cigarette_count`：固定一天观察窗内平均吸烟的卷烟等效支数，单位 `1`（计数）；表示支数而非包数。不要把烟草克数、雪茄数、电子烟吸口数直接等同为卷烟支数。

按结局仅需提供两种暴露指标中的一种。不要同时索取不需要的暴露值。`--age` 以岁填写，`--sex` 为 `male/female` 或 `男/女`。

```bash
python3 scripts/personal_report.py --measurements smoking.csv --outcome lung_cancer --age 57 --sex male --out out
```

全部结局支持论文印出的5、10、20、40暴露点及各结局特有的第85百分位暴露点；详见结局表。不四舍五入、不插值、不外推，也不要让用户更改真实输入来凑点。非表值返回退出码3及 `out/problems.json`，解释缺少可计算的表值；并非要求用户重新测量。

缺项、错单位、范围不合理或不适用的输入均退出3；错误报告同样包含论文卡片和边界。成功生成 `out/report.md` 和 `out/result.json`。全部运行离线；不要向用户索取论文、补充表、代码仓库或公共数据。

## 假设暴露点比较

仅当用户主动提供另一暴露点时，添加 `--targets targets.csv`（相同表头，只含所选结局的暴露指标）。输出 `out/levers.json`，逐项对比两个人群表值。只接受印出的精确点；不计算局部敏感度或差值区间。不建议目标值，也不把差值说成减量或戒烟后的风险下降。累计包年不能倒退，较低包年只能表示另一段假设历史。

## 报告必须保留

中文报告先放由清单渲染的论文卡片，再给结果。说明95%不确定区间包含研究间异质性，星级是关联证据强度。RR不是个人患病概率；小于1的帕金森病关联不支持吸烟预防疾病。

边界原文：本结果是当前吸烟者相对于从不吸烟者的人群关联，不是个人发病概率；不能预测减量或戒烟后的获益，不能据此开始或停止任何药物。
