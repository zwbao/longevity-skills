# 研究核对

- 研究设计：人体观察研究的系统综述及原创荟萃重估方法研究。Europe PMC（PMID36216941）出版类型为Journal Article、research-article、Research Support, Non-U.S. Gov't；不是随机试验。清单evidence标为method，概括新的证据负担分析框架，不宣称干预因果效果。
- 样本：正文报告筛查21,108条2018年5月1日至2022年5月31日记录，汇总1970–2022年793项研究。剂量反应使用前瞻队列和病例对照；心血管年龄曲线还使用横断面年龄分层资料。没有本论文独立招募的推导/验证人群，也没有统一可加总的参与者总数。
- 补充表3逐研究列出病例、对照、暴露者、样本量、人年、性别、年龄、结局及随访；多个结局可来自同一研究，不能相加为独立人数。补充表5的剂量反应数据为559个独立来源、634个来源-结局组合、2,575条观察；心血管年龄模式为159个独立来源、244个组合、1,318条观察。该表不能与正文793项研究简单相加或等同。
- 正文示例组：肺癌25项前瞻队列+53项病例对照，371条观察、25个地区；2型糖尿病24项前瞻队列+4项病例对照，102条观察、15个地区；慢阻肺正文写11项前瞻队列+4项病例对照、51条观察、36个地区，但表2写13项研究。保留差异，不推算一个“修正”总数。
- 物种：人（human / Homo sapiens）。无本文新做的动物或细胞实验。
- 利益冲突：Competing interests声明作者无利益冲突。资助为Bill & Melinda Gates Foundation和Bloomberg Philanthropies。
