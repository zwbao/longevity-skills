# 论文、补充材料、代码、同名的另一个东西

| | 内容 |
| --- | --- |
| 报告声称 | 中国 60 岁及以上社区老人中，三年间小腿围的绝对和相对减少都与随后自报跌倒的比值比升高有关；绝对减少 5 cm 及以上、相对减少 20% 及以上的档关联最强，女性和 80 岁及以上更明显。作者认为监测小腿围变化可作为低成本的跌倒风险评估辅助。 |
| 附录里实际有什么 | 正文表 2–4 印出了全部分档比值比和置信区间。Supplement 1 是 eTables 和 eFigures（流程图、敏感性分析等），本周没能下载，仓库里没有它的内容；这不等于论文没公布。 |
| 代码实际算什么 | 论文没有提供代码。本技能按方法里写明的公式算两次之差和百分比变化，按印出的切点分档，再查回表 2–4 的比值比；不拟合、不外推。 |
| 同名的另一个东西 | 亚洲肌少症工作组 2019 共识（Chen 等，J Am Med Dir Assoc 2020，doi:10.1016/j.jamda.2019.12.012）用单次小腿围切点（男 <34 cm、女 <33 cm）做肌少症病例发现，那是单次测量的筛查界值，不是这里的“两次之间减少多少”，本技能不用。 |
