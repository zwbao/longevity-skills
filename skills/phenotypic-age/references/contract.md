# 产品合同

1. 用户提供实足年龄与同一次、空腹至少 8 小时采血的九项血检原始浓度，可选提供部分血检目标；支持年龄 20–84 岁。
2. 技能已读取公开全文、正式更正、全部八个补充文件和原始方法 Table 1，并冻结所需常数；运行时不下载队列，不向用户索要公共数据。
3. 报告只计算临床表型年龄、表型年龄减实足年龄，以及目标情景下的数学变化；不计算参考回归参数未印出的 PhenoAgeAccel、风险五分位、病种风险或寿命。

## 来源与全部模型参数

主文 Liu 等，PLoS Medicine 2018，15(12): e1002718，
[DOI](https://doi.org/10.1371/journal.pmed.1002718)。公式必须使用
[2019 正式更正](https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.1002760)，
而不是有缺失步骤的原文。

更正的 xb 方程逐项打印：

| 项目 | 输入单位 | 系数 |
|---|---|---:|
| 截距 | — | -19.907 |
| Albumin | g/L | -0.0336 |
| Creatinine | umol/L | 0.0095 |
| Glucose | mmol/L | 0.1953 |
| ln(CRP) | 先用 mg/dL，再取自然对数 | 0.0954 |
| Lymphocyte Percent | % | -0.0120 |
| Mean Cell Volume | fL | 0.0268 |
| Red Cell Distribution Width | % | 0.3306 |
| Alkaline Phosphatase | U/L | 0.00188 |
| White Blood Cell Count | 1000 cells/uL，等于 10^9/L | 0.0554 |
| Chronological Age | 年 | 0.0804 |

更正的其余两个方程：

```
M = 1 - exp(-1.51714 * exp(xb) / 0.0076927)
PhenotypicAge = 141.50 + ln[-0.00553 * ln(1-M)] / 0.09165
```

脚本先代入 `-ln(1-M) = 1.51714*exp(xb)/0.0076927`，得到
`141.50 + [ln(0.00553)+ln(1.51714)-ln(0.0076927)+xb]/0.09165`。
这只是代数展开，避免 M 舍入为 0 或 1，不拟合、不推导额外精度的常数。
未调用任何第三方 PhenoAge 实现，也没有从已有技能抄入更高精度的权重。
不输出 M，因为本技能合同限表型年龄读出。

## 单位冲突与输入合同

本文 S1 Table 将白蛋白写成 mg/dL、CRP 写成 g/L，和作者所引用的原始方法
[Levine 等，Aging 2018，Table 1](https://www.aging-us.com/article/101414/text)
中的 g/L、mg/dL 冲突。采用该原始方法明确列出的单位，不能按汇总均值猜单位。
原始 Table 1 中 ALP 系数四舍五入为 0.0019；本实现采用更正方程明确写出的 0.00188。
原文血糖 0.0195、RDW 0.3356 也由更正中的 0.1953、0.3306 替换。

输入换算由 skillkit 按 manifest 执行：白蛋白 g/dL ×10；肌酐 mg/dL ×88.4；
葡萄糖 mg/dL ×0.0555；CRP mg/L ×0.1；ALP ukat/L ×60；WBC 10^3/uL ×1。
肌酐与葡萄糖使用仓库约定的有限精度临床换算因子（对应分子量 113.12、180.16），
不声称它们具有无限物理精度。每次转换使用上述固定因子，不靠数值大小猜单位。
CRP 必须为正，不设置检测限替代值；不对高低结果裁剪或对表型年龄设零下限。

manifest 中血检范围是输入错误筛查的宽范围，不是论文推导的正常范围或健康目标。
20–84 岁的范围来自正文及 Fig 1；185 名最高龄受试者被顶码为 85，故本实现
不把精确的 85 岁以上年龄代入来声称已验证。性别不进入本公式。

## 目标情景

`--targets` 允许九项血检的非空子集，单位、范围与当前测量一致；拒绝年龄及未知项目。
`levers.json` 给出所有十个数值输入的当前敏感度，其中年龄标为不可修改。
普通项斜率为 `weight/0.09165`，CRP 原始浓度项为 `0.0954/(0.09165*CRP)`。
同时计算每项单独替换和所有目标同时替换。没有自动推荐的目标值或排序健康建议。

## 验证缺口

已查全文、Tables 1–4、Figures 1–7、S1 Appendix、S1–S2 Fig、S1 STROBE、
S1–S4 Table、2019 更正；未发现一组完整年龄与九项血检对应的打印表型年龄。
引言以 50 岁人的表型年龄 55 或 45 岁解释含义，没有提供九项输入。
S1 Table 给出各项边际均值，没有给出该输入组合的预测值；不能将均值组装成假算例。
Fig 3 的相关系数与残差分布、Fig 6 的人群中位寿命都不是个人公式的输入输出对。
数据声明链接 NHANES 门户，但没有随文发布逐人预测表或专用计算仓库。

因此 validation 与 inputs_status 均为 draft。先写 tests/test_manifest.py，再写实现。
测试用明确标记的合成输入和 Decimal 逐步展开的打印公式检查代数一致性，
检查输入转换、退出码、空结果、敏感度和目标情景；没有硬编码自算的“论文预期值”。
这些工程检查不能升级为 reproduced，也没有用第三方输出反推常数。

边界: 这是观察性人群模型的表型年龄估计，不能诊断疾病、预测个人寿命或证明干预能逆转衰老，不能据此开始或停止用药。
