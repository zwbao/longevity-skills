# 证据核对

论文：Sun 等，The Lancet Public Health，2022；7(12):e994–e1004，DOI 10.1016/s2468-2667(22)00110-4。研究为原创前瞻性观察队列结合全国横断面调查与死亡率资料，不是随机试验或系统综述。

全部人群：CKB 最初招募 512,725 名 30–79 岁成年人；主分析排除冠心病、脑卒中、癌症和 BMI 缺失后为 487,209 人，男性 199,238、女性 287,971；进一步排除 COPD/哮喘的呼吸病分析为 451,233 人（男性 181,544、女性 269,689）。这不是外部预测验证集。主分析随访中位数 11.1 年、记录 42,496 例死亡。CNHS 2015 使用至多 171,127 名 30–84 岁成人（男性 80,650、女性 90,477），饮食分析有 71,010 人，完整生活方式组合有 67,798 人；各因素分母不同。GBD 2015 提供年龄和性别分层人口死亡率，不是新增招募队列。主文还报告排除前两年死亡及不同分层的敏感性分析。

物种：人（human）；没有动物或细胞实验。
