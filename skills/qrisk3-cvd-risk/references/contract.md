# 产品合同

用户提供自己的年龄、模型性别、最近血压、此前五年重复血压的标准差及记录数、BMI、TC/HDL 比值、真实 Townsend 评分、族裔、吸烟、病史和用药状态，所有未知均保持缺项。
技能自行取得并冻结 ClinRisk 2017 公开 C 代码存档中的完整男女模型 C 参数；全文、两份补充 PDF 和图中示例已由作者/期刊的 Europe PMC 开放副本核查，用户不承担材料获取。
报告只给出十年冠心病、缺血性卒中或 TIA 复合结局风险及用户目标情景的模型差异，不给寿命、诊断、治疗收益、剂量或启停药建议；个人示例缺 Townsend 输入，验证状态保持 draft。

## 参数来源及公式

原始入口 https://qrisk.org/three/src.php 和 https://qrisk.org/src.php 目前返回404；论文 Data sharing 明确以 GNU LGPL v3 发布。冻结存档：sisuhealthgroup/qrisk3，commit `019ded12978a570b4be21957e838fa954d6389b2`，`src/lib/original/qrisk3.c`。保留原 ClinRisk 2017 头、函数、注释及全部数值。不是采用该库的 JavaScript 重写。未调用当前 QRISK 在线计算器取得测试输出。文件 SHA256 在 skill.json。

`presets.py` 是上述 C 两个函数的逐句 Python 翻译，去除 C 类型声明、分号，将数组改为列表，保留算式和所有小数。风险是 `100 * (1 - S0(10)**exp(a))`，a 为所有中心化项、类别权重及年龄交互的和。

| 需要的参数 | 原始 C 位置 | 实现 |
|---|---|---|
| 十年基线生存率 | `cvd_female_raw` / `cvd_male_raw` 的 `survivor[10]`，0.988876402378082 / 0.977268040180206 | 仅用10年，其他数组位置为0不是有效其他年限 |
| 族裔及吸烟权重 | 两函数的 `Iethrisk` / `Ismoke` | 使用明确整数编码，不用缺失值补0 |
| 年龄变换 | 女性 `(age/10)^-2`、`age/10`；男性 `(age/10)^-1`、`(age/10)^3` | 与原始C一致 |
| BMI变换 | `(BMI/10)^-2` 及该项乘 `log(BMI/10)` | 男女中心化常数不同 |
| 中心化常数 | 两函数 `Centring the continuous variables` | 逐项保留，不能拿Table 1总体均值替代 |
| 主效应系数 | `Sum from continuous values`、`Sum from boolean values` | 全部使用原始C精度 |
| 年龄交互系数 | `Sum from interaction terms` | 含吸烟、疾病、BMI、家族史、血压、Townsend；男性ED，女性SLE |

没有重估、反推或拟合任何模型常数。只实现有完整公开代码的模型 C；不把 SD=0 伪装成模型 B，也不把论文中的 HR 表当作整套回归系数。输入合理范围（除年龄、类别编码和至少两次记录）为工具的数据质量检查，不是论文的临床阈值；不外推到25–84岁之外。

## 输入操作定义

- 基线无冠心病、缺血性卒中或TIA且未用他汀。用药不是仅作可忽略的上下文；是否入组由明确的两个字段控制。
- 糖尿病类型互斥。高血压需诊断并有至少一种降压药。论文药物基线定义：至少两张处方，最近一张在基线前28天内；全身性皮质激素包括口服或肠外，不把外用自动当作有。
- 房颤包括房扑、阵发房颤；肾病包括记录的3–5期及论文 Box 1 所列重大慢性肾病。不是直接用一次肌酐自动确诊。
- 亲属是一级亲属，冠心病发生年龄小于60岁；不是泛指家族长寿或所有中风史。
- 严重精神疾病遵循论文临床记录字段；Box 1 列 psychosis、schizophrenia、bipolar affective disease，正文/当前官网措辞不完全一致，本工具不从聊天内容判断病史。
- 标准差需五年窗口至少两次重复血压。脚本不替用户查日期和重算原始序列；样本标准差 n−1 是公开的整理约定，论文未明确分母。零只允许真实多次记录均相同。
- 压力单位接受 kPa，按仓库单位表 `kPa × 7.500617 = mmHg`；同一因子用于SD。TC/HDL是无量纲比值，BMI为kg/m²，Townsend为score。没有引入可疑LOINC，仅收缩压用8480-6。

在写计算实现前，已检查正文 Table 6、Figure 3/4、补表1–6和全部8页补图，并先写 `tests/test_manifest.py` 中不需缺失输入的逐项HR测试。

Table 6 列出六个人的年龄、BMI、TC/HDL、SBP、族裔、吸烟、病史和SD，以及模型A/B/C的风险，但没有 Townsend。第六例SD写作 `No`，不能擅自解释成0。

Figure 3 图注印 `22.5%`、44岁、白人男性、重度吸烟、比值2、SBP132、SD10、BMI31.22，房颤、ED、偏头痛和激素使用。Figure 4 印 `7.5%`，SD0、无房颤无ED，其余同前。截图显示邮编空白，并明确提示：`Your score has been calculated using estimated data, as some information was left blank.` 截图没有说明内部补了多少 Townsend，图注也未说明，因此不能用零或从结果反推Townsend来补全测试；BMI截图由85kg/165cm计算，而图注四舍五入，也不是完整精确输入。补表/补图未补齐该字段。

`test_printed_term_hazard_ratios` 核对正文 Table 3/4 模型 C：类风湿关节炎HR女1.24、男1.23；TC/HDL每增加1的HR女1.17、男1.19。容差0.005来自印出两位小数。这些是逐项效应核对，**不是完整个人绝对风险复现**；validation保留draft，inputs_status也保留draft。

`test_reference.py` 编译冻结的原始C到临时目录，用不同年龄、全部族裔、全部吸烟编码和随机有效病史/连续量比较男女模型共360例；期望值由原始C提供，未写入本脚本输出充当真值。这只是移植一致性，不是独立模型验证。还测试输入失败退出3、缺项、不适用人群、互斥糖尿病、单位错误、超范围、女性不需要ED、结果和目标情景文件及旧结果清理。

## 目标与敏感度

连续项在当前值附近作中心差分（边缘用单边），步长为数值算法参数 `1e-4 * max(1, abs(x))`，不是论文效应常数。离散项给合法类别的模型对照，糖尿病保持类型互斥；年龄给前后一个周岁的对照。性别对照缺男性ED输入时留空。记录数及适用人群门槛不是模型项，不算导数。

仅BMI、血脂比值、SBP、SD可作为用户提供的目标；Townsend、病史、药物、性别、年龄、族裔和吸烟类别不开放为行动目标。单项及联合目标均用同一函数重算，写百分比和百分点变化；不把模型差当可获得的治疗收益。
