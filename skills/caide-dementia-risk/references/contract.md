# 产品合同

用户提供同一中年基线的年龄、性别、已完成教育年限、收缩压、BMI、总胆固醇与休闲活动达标状态；选择模型 2 时另提供明确的 APOE ε4 携带状态，可另给四项可变指标的目标。
技能自行核对并冻结原文表 2、表 3 和方法段常数，运行不下载资料，不要求用户提供论文或队列数据。
报告只给所选模型的逐项分数、总分、原队列分组发生率和置信区间、20 年公式估计及用户指定目标情景；不能给出诊断、干预的因果效果或药物指令。

## 方法与参数出处

Kivipelto 等，The Lancet Neurology 2006;5:735–741，DOI 10.1016/s1474-4422(06)70537-3。

表 2（p737）的列为每种模型的 β coefficient、p、OR (95% CI)、Score。本实现直接使用 Score 列，不用原始回归截距替代评分换算公式。文中描述乘以 2.5 后四舍五入；已经印出的整数分值是实现依据。

| 因素与原文类别 | 模型 1 分 | 模型 2 分 |
|---|---:|---:|
| 年龄 <47 / 47–53 / >53 | 0 / 3 / 4 | 0 / 3 / 5 |
| 教育 ≥10 / 7–9 / 0–6 年 | 0 / 2 / 3 | 0 / 3 / 4 |
| 女 / 男 | 0 / 1 | 0 / 1 |
| 收缩压 ≤140 / >140 mmHg | 0 / 2 | 0 / 2 |
| BMI ≤30 / >30 kg/m² | 0 / 2 | 0 / 2 |
| 总胆固醇 ≤6.5 / >6.5 mmol/L | 0 / 2 | 0 / 1 |
| 活动 Active / Inactive | 0 / 1 | 0 / 1 |
| APOE Non–ε4 / ε4 | 不使用 | 0 / 2 |

方法段 p736：p = exp(z)/(1+exp(z))，z = β0 + β1 + β2 × score。模型 1 为 (-7.406, 0.796, 0.401)，模型 2 为 (-8.083, 1.020, 0.390)。β1 已经是随访 20 年的贡献，不能再乘 20；不能混用表 2 的截距与系数。仅提供原文的 20 年时距，不提供任意年数推算。

表 3（p737）各模型列为 Score、All/demented (n)、Risk (95% CI)。模型 1 五档 0–5、6–7、8–9、10–11、12–15 对应 1.0、1.9、4.2、7.4、16.4%；模型 2 五档 0–5、6–8、9–10、11–12、13–18 对应 0.3、1.7、4.6、4.4、16.3%。其置信区间端点全部照表冻结，不平滑非单调分组，不裁掉模型 2 首组的 -0.3% 下限。

## 先写测试的印刷示例

表 4（p738）按低/中/高风险及模型 1/2 的顺序，分数为 0、0、10、10、15、18，公式风险为 0.13%、0.09%、6.91%、4.06%、35.55%、48.93%。

- 低：年龄 <47、女、教育 ≥10、SBP ≤140、BMI ≤30、TC ≤6.5、Active；模型 2 为 Non ε4。
- 中：年龄 47–53、女、教育 7–9、SBP >140、BMI ≤30、TC >6.5、Inactive；模型 2 为 Non ε4。
- 高：年龄 >53、男、教育 ≤6、SBP >140、BMI >30、TC >6.5、Inactive；模型 2 为 ε4。

表 4 只给类别，未给精确原始测量。测试取 46/47/54 岁、10/7/6 教育年、140/141 mmHg、30/31 BMI、6.5/6.6 mmol/L 来进入这些印出的类别；这些代表数不是论文中的个体测量，也不作为印刷验证值。六项分数都精确复现；六项风险均与印刷值相差不超过 0.005 个百分点（百分比两位小数的半个末位），无需反推或拟合常数。另按表 3 检查每个整数分数的查表结果。

## 输入与情景约定

年龄仅接收原文基线范围 39–64 岁。教育是已完成整年，拒绝小数以避免 6–7 或 9–10 间的隐含分类假设。SBP、BMI、TC 切点严格为大于；等于切点不加分。活动采用方法段（频次、时间、强度）完整定义，不能缩成任意运动。性别按原文两类，不推断。基因状态须明确 0/1，不将缺失当 0。

生理范围（血压 60–300，BMI 10–80，TC 0.5–20，教育 0–30）是输入质量检查，不是论文治疗阈值。换算沿用仓库单位表：kPa → mmHg 乘 7.500617；umol/L → mmol/L 乘 0.001；胆固醇 mg/dL → mmol/L 乘 10/386.65（molar_mass 386.65，沿用仓库 cholesterol 约定），不四舍五入后再分档。别名输入缺血压/胆固醇单位时停止。

分档函数不能给出有用的平滑导数。levers.json 对每个输入列出原文各类别下的单项分数和公式风险变化，注明 category_transition；年龄、性别、教育和 APOE 列为不可作为目标。仅收缩压、BMI、胆固醇和活动可由用户指定目标。单项与联合情景重算相同函数，不声称可在现实中减少相应百分点的风险。
