# 证据与实现范围

出处：Ashwell 等，Obesity Reviews，2012，13(3):275–286；DOI 10.1111/j.1467-789x.2011.00952.x。卷期年为 2012，在线发表在 2011，不混用。

研究设计：PubMed/Europe PMC 标为 Meta-Analysis、Systematic Review；不是干预试验。`evidence` 用 `review`。

全部样本组：正文报告 31 篇研究，26 项横断面、5 项前瞻性；28 篇含男性、30 篇含女性，合计男性 123,231、女性 182,620，总计 305,851。不同族群在分析中可拆成研究组，不能把研究组数当论文数；没有单独推导或外部验证队列。正文总体年龄概述为 18–100 岁。Table 1 部分行的年龄下限更低，Welborn 行标为前瞻性而正文设计计数的引用归入横断面，正文还出现 33 项的表述；保留正文总数，不据此重建原始队列。Table 2 和 Table 3 的男性全结局研究组数也不同，故不将这些汇总表当作个人验证集。

物种：人（human）；无动物或细胞实验。

利益冲突：第 285 页声明无利益冲突，同时披露 MA 设计并拥有 Ashwell Shape Chart 的版权，非营利分发给卫生专业人员；研究无外部资金资助。本技能不复制该图。
