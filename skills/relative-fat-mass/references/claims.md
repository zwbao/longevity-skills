# 证据核对

- 研究设计：人体横断面分析和预测方程开发/验证；Europe PMC PMID 30030479 标为 research-article / journal article（非综述）。不是干预试验或纵向减脂研究。
- 全部样本组：NHANES 1999–2004 推导 12,581 人（女 6,261、男 6,320），年龄编码 20–85；NHANES 2005–2006 独立样本验证 3,456 人（女 1,700、男 1,756），20–69 岁；合并内部 bootstrap 验证 16,037 人（女 7,961、男 8,076）。没有另外的治疗组/对照组。补充方法最初调查人数分别为 31,126 与 10,348，不能当作最终分析人数。
- 物种：人（human / American adult individuals）；无动物或细胞实验。
- 利益冲突：Competing Interests 声明无利益冲突。NIH DK29867、DK27619 资助 R.N. Bergman；论文称资助方未参与设计、数据收集分析解释、写作或投稿决定。

| 研究泛化仍有限 | 补充图 6、8 提示较瘦者表现较弱；方法列妊娠、身高、体重及造影等排除项 | 年龄与身高超出相关范围时提示；其余限制始终显示 | 不用本研究验证儿童、运动员、亚洲人或特定疾病人群 |
