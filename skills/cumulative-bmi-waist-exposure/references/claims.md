# 论文、补充材料、代码、同名的另一个东西

- 研究设计：前瞻性社区队列（江苏如皋老年纵向研究 RLAS），2014、2017、2019 三轮测 BMI 和腰围，2021 轮测生物衰老指标；原创研究（期刊页面标为 ORIGINAL ARTICLE；PubMed 出版类型未核对）。
- 样本：RLAS 2014 年入组 1788 名 70 岁以上老人；三轮都参加的 1109 人中，剔除肥胖指标缺失 73 人、衰老指标缺失 300 人、肥胖指标极端值 49 人，分析样本 687 人（男 317、女 370）；有长寿多基因评分的 502 人（低 PRS 250、高 PRS 252）。
- 物种：人（Homo sapiens）。
- 利益冲突：作者声明无利益冲突。

| | 内容 |
| --- | --- |
| 论文声称 | 累积 BMI 和腰围暴露都与 2021 年更高的 KDM-BA 和 PD 相关；单次（基线）肥胖只与 KDM-BA 相关；长寿多基因评分低的人，cWC 与 KDM-BA 的关联更强（交互项 −0.55）。 |
| 补充表里实际有什么 | 补充方法（变异度 CV、VIM、ARV、SD 的定义）；补充表 1：11 个 SNP 的染色体位置、效应等位基因、邻近基因、比值比和 P 值（正文说按发现 GWAS 的 β 加权，表里印的是比值比）；补充表 2–12：各模型的 β 和置信区间。没有三分位界值，没有 PRS 中位数，没有个人算例。 |
| 代码实际算什么 | 论文写明数据和 R 4.3.1 代码只能向 Zuyun Liu 申请，没有公开仓库。本技能按方法里的切点算每轮超出量，再用梯形面积乘间隔年数（操作定义见 contract.md）。 |
| 同名的另一个东西 | KDM-BA 和 PD 本身来自 Liu 2021（J Gerontol A，十项血检），本技能不算它们；仓库里的 accelerated-biological-aging-risk 等技能读血检算生物年龄，与这里的累积肥胖暴露不是同一个量。 |
