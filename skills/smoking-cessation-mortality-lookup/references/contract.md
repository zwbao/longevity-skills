# 产品合同

1. 用户提供男性性别、当前年龄、经核实的实际吸烟模式，以及已戒烟者的真实戒烟年龄；均为个人问卷信息。
2. 技能使用已从可读论文表5和图4正文冻结的分组与数值，运行不联网，不向用户索要论文或队列数据。
3. 报告允许给出匹配的历史队列年死亡率、该单元死亡数、同龄参照组及原表持续吸烟/不吸烟比值，另对已戒烟者匹配队列近似寿命差；不计算个人死亡概率、个人戒烟因果获益、剩余寿命或完整生存曲线。

流水线已授权生成Tier A技能；依照用户流水线规则直接完成合同和实现。

## 精确定义

- 表5限1900–1930年出生、1951–2001年随访的英国男性医生。个人用现代年龄匹配时仅获得历史队列参考，不声称同属推导出生队列，也不作时代或地区校准。
- 吸烟者限论文的持续仅吸卷烟者及其戒烟者；混合烟草、电子烟、复吸、间歇使用没有该查表的对应分组。编码是本工具接口，不是论文评分或严重程度。
- 年龄区间为 `[35,45)`、`[45,55)`、`[55,65)`、`[65,75)`、`[75,85)`；戒烟年龄为 `[25,35)`、`[35,45)`、`[45,55)`、`[55,65)`。这些半开区间按论文整岁分组解释，不对小数年龄取整。
- 戒烟年龄的0–120范围仅用于录入检查；实际支持范围更窄。月→年为1/12，取自仓库时间单位定义，不按365天近似。无化验指标或LOINC。
- 表5死亡率单位为每千名男性每年死亡数；脚注说明为两个五岁年龄组率的均值。原表括号内是观察死亡数，不是分母或事件概率。绝不将率直接写成百分比或乘十生成十年风险。
- 最右列印出的持续吸卷烟者/不吸烟者比值为独立冻结值，不对已舍入率重新相除；尤其35–44岁行2.7与1.6相除不等于印出的1.6，不擅自“修正”。该比值不是所匹配戒烟者的相对风险。
- 表5仅有35–44、45–54、55–64岁戒烟列；仅报告后续年龄段的率。25–34岁戒烟没有这一列；仍在戒烟年龄段的单元是原文空格。所有此类值与队列死亡数保留null，但返回已印出的参照列。
- 图4图注给出25–34、35–44、45–54、55–64岁戒烟组；正文和Discussion对应概括为约10、9、6、3年寿命差。只对已发生戒烟的分组作此近似描述，不在年龄点间插值。这些不是逐岁精确函数，也不是从当前年龄起的剩余寿命。所有组均可能有反向因果；约60岁戒烟者的60–64岁死亡率还含作者插值。

## 不重建的内容

表5不是完整的五岁分层、按日历年标准化的生存分析输入。Methods描述了五岁生存概率和按时期加权的方法，但没有逐项列出图4所需的全部分层死亡数、人年与权重。故本产品只做印出结果的查表，不重新计算图4曲线或寿命积分，不推导精细常数。表5和图4没有个人预测区间。

本技能不是个人可定目标的风险方程。输入是既往史，当前年龄和已发生的戒烟年龄不能改变；因此不提供targets或levers。未来戒烟计划不能冒充既往戒烟史，不能从这张历史表导出个人干预效果。

## 验证

`tests/test_manifest.py`先于实现写入，期望值逐项来自表5原始单元和图4正文。表5全部非空率、死亡数、原表比值精确匹配；CLI示例选择65–74岁行、45–54岁戒烟列，核对31.7、331和对应参照。图4测试核对30、40、50、60岁分别映射到约10、9、6、3年。没有重新拟合或反推常数。

测试还验证边界生日、原文空格、中文别名/月单位、性别限制、条件必填、矛盾历史、未知项目和错单位退出3，以及成功/失败之间不残留旧结果。
