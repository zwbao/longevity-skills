# 32 项衰弱指数：合同、数值来源与核对

## 产品合同

1. 用户提供自己 32 项问卷的答案：30 道是/否题、CES-D-10 抑郁量表总分，可选已换算到 0–1 的认知缺损分；年龄可选。
2. 技能自带补充表 2 的计分规则、正文的切点和结果正文印出的风险比，不向用户要论文、补充表或 CHARLS 数据。
3. 报告给出衰弱指数（缺认知分时给区间）、论文分档；在论文人群内（45 岁及以上、没有心脏病、中风和癌症）的衰弱前期或衰弱，列出表 3 模型 2 相对强健的心血管病、心脏病、中风风险比。不能算的：轨迹分组（潜类别模型参数没印出）、个人发病概率（论文没有基线风险）、从记忆和定向原始分导出认知缺损分（换算没印出）。

## 方法（照原文）

- “The FI score was calculated as the sum of deficit scores divided by 32, yielding a continuous value from 0 to 1.”
- “robust (FI ≤ 0.12), pre-frail (0.12 < FI ≤ 0.25), and frail (FI > 0.25)”。等于 0.12 归强健，等于 0.25 归衰弱前期。
- 第 1–12 项：Yes = 1, No = 0；第 13 项自评健康：Poor or fair = 1, excellent/very good/good = 0；第 14–30 项：Yes = 1, No = 0；第 31 项：CESD-10 >10 = 1, <=10 = 0；第 32 项：continuous deficit score，0 to 1。

## 操作定义（论文没有写死的地方）

- 文本答案：是、有、yes、有困难 读成 1；否、无、no、没有困难 读成 0；自评健康 一般、不好、差 读成 1，极好、很好、好 读成 0（照第 13 项规则）。其他文字不猜，退出码 3。
- CES-D-10 输入范围 0–30（十题，每题 0–3 分）。论文只印出 >10 这一个切点；“10.5”这类非整数照规则计 1。
- 认知项：论文写“cognition score derived from memory test score and orientation test score”，没有印出满分和方向。本技能不换算，只接受 0–1 的缺损分（越高越差）。不填时，按公式指数一定落在 [S/32, (S+1)/32]（S 为前 31 项之和），报告这个区间；两端分档相同时给分档，否则写“不能确定”。这是公式的数学结论，不是估算。
- 缺其他任何一项都不计算：论文把衰弱指数缺失的人排除在外，也没有按实际项数换分母。
- 风险比只在论文人群内列出：论文排除了基线有心血管病（心脏病、中风）和癌症的人，年龄 45 岁及以上。CKM 分期本身没有让用户输入：没有心血管病就落在 0–3 期。

## 核对

论文没有印出某个人 32 项答案对应的指数，没有可复现的个人算例；`validation` 保持 `draft`。测试核对：常数与补充表 2 和正文一致（32 项、0.12、0.25、CES-D-10 >10）；切点边界（0.12 归强健，0.25 归衰弱前期，4/32 = 0.125 归衰弱前期，9/32 归衰弱）；缺认知分时的区间和“不能确定”；文本答案的读取；风险比与正文一致；是/否项不是 0/1、CES-D-10 超范围、缺项、单位不对时退出码 3。

## 没有做的

- 轨迹分组：需要潜类别模型每类的截距、一次和二次项及方差，论文只画了图 2，没有印出参数。
- 比值比（轨迹 1.87、3.52 等）：属于轨迹分组，个人归不了组，报告不引用为个人结果。
- 个人心血管病概率：论文没有给基线风险或生存函数。
- `--targets` 和 levers：衰弱指数是缺陷计数，不是可对着单项定目标的风险方程，不提供。
