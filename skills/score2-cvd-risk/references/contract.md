# 产品合同

用户提供年龄、论文模型性别、当前吸烟状态、收缩压、总胆固醇、HDL 胆固醇、所在国家对应的欧洲风险地区，以及既往心血管病和糖尿病是否存在；可提供自己的目标值。技能内置更新附件中的连续模型参数与国家分组，不让用户下载任何公共研究文件。报告只计算适用人群的十年首次致死或非致死心血管事件风险，以及固定年龄、性别和地区下的目标情景变化；不计算寿命、疾病诊断、药物剂量、治疗收益或启停方案。

本合同按已授权的 LONGPI_PIPELINE 流程实施。来源为 Hageman 等，European Heart Journal 42(25):2439–2454，2021，doi:10.1093/eurheartj/ehab309。

## 可行性与参数来源

2026-11-25 已读取期刊文章页（通过其公开 article-minimal 页面）、PMC 全文及期刊链接的唯一附件 ZIP。ZIP 内的 `SCORE2 Updated Supplementary Material.docx` 和 `SCORE2_Appendix_1.docx` 均已打开、提取正文和表格。正文与附件未发布 GitHub、Zenodo、OSF 等成品代码或参数数据集；正文明确 Stata 实现须向作者索取，队列数据须各队列批准。运行此冻结方程不需要重新获取研究队列。

所有计算参数按更新文件 Supplementary Methods Table 2（变量变换、男女 Log SHR、baseline survival）、Table 3（四地区男女 Scale1/Scale2）原样冻结到 `scripts/presets.py`。不使用 Table S7 四舍五入后的 SHR 取对数；不使用其他计算器或 SCORE2-Diabetes 的系数。Table 4 提供独立于参数表的逐项示例。没有重建或拟合任何常数。

## 先写测试与复现

首先写 `tests/test_manifest.py` 的两个 printed 测试，运行确认缺少实现失败，然后才写计算脚本。断言值均来自下列印出的示例。

正文 Results、Figure 3 说明及 Supplementary Figure S11：年龄 50、当前吸烟、SBP 140 mmHg、TC 5.5 mmol/L、HDL 1.3 mmol/L；男性 low 5.9%、very_high 14.0%，女性 low 4.2%、very_high 13.7%。四个连续模型结果均在 0.05 个百分点内，符合正文一位小数的舍入精度。这一组支撑 reproduced 标记。

更新 Supplementary Methods Table 4：年龄 50、当前吸烟、SBP 140、TC 6.3、HDL 1.4。男性 LP 0.3221、未校准概率 0.0541；女性 LP 0.39788、未校准概率 0.0332。按 low、moderate、high、very_high 顺序，男性最终概率 0.0631、0.0811、0.0881、0.1506，女性 0.0434、0.0523、0.0713、0.1414。

Table 4 第 3 步明确把已舍入的 0.0541/0.0332 代入校准式，脚本则保留全部中间精度。因而不能要求它们在最终半个末位内完全相同：女性原始未校准概率为约 0.0331629，最终 very_high 约 0.141267，而表格为 0.1414。测试对 LP 采用 1e−8，对未校准概率采用 0.00005，对最终概率采用 0.00025（0.025 个百分点）：中间概率舍入半单位 0.00005，经该示例校准曲线最大斜率小于 4 传播，再加末位舍入 0.00005。八个概率均满足此传播误差界；不是修改常数或从自算结果设定期望值。正文示例仍以更严格的 0.05 个百分点检查。

## 输入、范围与单位

年龄输入接受 40–69（含端点），这是本技能保守的个人使用范围；论文为了估计年龄交互项在 40–79 岁推导，`population.age_years` 因此记录 40–79。70 岁及以上不自动换用 SCORE2-OP。使用者需显式确认属于 Table S6 的校准国家、无既往 CVD、无糖尿病；缺失不当成 no。

血压 70–250 mmHg、TC 1–15 mmol/L、HDL 0.2–5 mmol/L 是工程输入防错范围，不是论文的诊断阈值或治疗目标；HDL 必须低于 TC。吸烟只接受 0/1，不接受人群吸烟率。所有测量通过 skillkit 按 manifest 解析，不凭数值猜单位。血脂 mg/dL→mmol/L 精确按所声明胆固醇摩尔质量 386.65 g/mol 使用 10/386.65；mg/L→mmol/L 为 1/386.65；这是单位换算而非模型参数。血压 kPa→mmHg 使用仓库单位表 7.500617。未声称核验 LOINC，故不填。

非 HDL 图表使用便于展示的分类值，不能用来替换连续模型中的 TC 与 HDL。没有实现个人高/很高风险治疗阈值，因为本产品是论文风险方程，不扩展为指南决策。

## 目标情景与错误输出

`--targets` 与测量文件同表头；允许 SBP、TC、HDL、当前吸烟中的任意非空子集。单独达成每项目标与同时达成全部目标均检查 HDL<TC。不允许修改年龄、性别、地区或病史。`levers.json` 采用 longevity-levers/1，连续指标给当前值附近每单位有限差分（以百分点计），吸烟给 1 相对 0 的离散模型差，不把二元变量做连续微分。固定上下文计算各单项目标及合并目标风险变化。没有目标时输出当前敏感度、空目标及零变化。

这是假设输入不同的模型比较，不能解释为改变输入导致的因果收益；不提供默认目标。尤其吸烟状态切换不是戒烟后立即恢复风险，HDL 关联不是提高 HDL 的治疗效应。

缺项、非数值、非有限值、未知单位、越界、重复冲突、未知指标、不适用人群及错误目标都退出 3。输出 problems.json、含论文卡片及边界的中文报告和 risk=null 的 result.json，并清除旧的 levers.json，避免上一轮数值混入失败报告。成功后删除旧问题文件。
