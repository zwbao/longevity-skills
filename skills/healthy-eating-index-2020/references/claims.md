# 证据核对

研究设计：PubMed（PMID 37201748）的Publication types标为Review。本技能据此设`evidence=review`，不因标题“更新”把它标成临床试验或新预测模型。论文复核美国膳食指南、NHANES摄入分布以及内容效度；明确除内容效度外没有对HEI-2020重新开展进一步评价。

全部样本组：摄入分布对照来自NHANES 2017–2018与2011–2012；正文说明分布结果未展示，没有给出这些比较的分析样本量。图4雷达图使用NHANES 2011–2018，含12—23月幼儿（另一个指数）、2—4、5—8、9—13、14—18岁儿童，以及19—30、31—59、≥60岁成人；两个年轻成人组在图中合并。各组分析人数未印出，不补写总人数，也不存在本工具声称的独立推导/验证人群。图4是人群估计，不是个人参考百分位。

物种：人（human），美国人群；没有动物或细胞实验。指南面向至少2岁人群，本技能不实现幼儿版。

利益冲突与财务披露：全文Footnotes分别声明无财务披露、无利益冲突。作者任职NCI或USDA相关机构，属于指数开发团队；没有把他们的机构任职隐去，也不推定存在未披露商业关系。卷期年2023，作者Shams-White等，与PubMed及PMC一致。
