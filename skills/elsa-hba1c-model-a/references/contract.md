# 产品合同与可行性核查

1. 用户提供当前 HbA1c（NGSP/DCCT 百分数）、基线年龄、论文性别编码、下一健康访视的指定间隔，并确认基线适用条件；可另外提供自己的 HbA1c 假设目标。

3. 报告仅给出指定间隔条件下的 Model A 研究概率、线性预测值和 HbA1c 情景差值，不算个体轨迹、不作诊断、不给药物剂量，不声称降低某项输入会产生对应的真实获益。

## 冻结公式与出处

补充 S2 第 31 页：对每个预测列 `z=(x-mean)/SD`，`eta=intercept+sum(beta*z)`，`p=1/(1+exp(-eta))`。
S4 第 32 页全部 Model A 参数见相邻 `model-s4.csv`，数值原样抄录并冻结于 presets.py：

| 列 | 变换 | 均值 | SD | 标准化系数 |
|---|---|---:|---:|---:|
| 截距 | 无 | — | — | -4.053 |
| HbA1c mmol/mol | 无 | 38.74 | 3.47 | 1.469 |
| 年龄（年） | 无 | 67.71 | 7.30 | -0.147 |
| 女性编码 | 0/1 | 0.57 | 0.50 | -0.067 |
| 到下次访视的年数 | 自然对数 | 1.56 | 0.26 | 0.507 |

没有中位数插补项或缺失指示项属于 Model A。所有输入必须齐全。
Model B 的 weekly vigorous activity 缺失指示项均值、SD、系数被 S4 脚注隐去，不能假设贡献为零，即便活动已观测也存在标准化后的贡献；因此不实现 Model B。
不重建 C–E、混合模型或 Transformer，不用人群 OR 充当个人概率。

正文 2.1 第 5 页：`IFCC mmol/mol = (DCCT percent - 2.15) * 10.929`。
本文 Table 1 脚注另列反向显示公式 `percent=0.09148*IFCC+2.152`，印出精度并非上述式的精确逆式。本实现沿用正文及作者预处理方向，绝不混用两套舍入常数或反求更多精度。
manifest 只能声明乘法单位换算，仓库单位表没有 mmol/mol；为不偷偷改变公共接口，输入限定为 `%`，其余单位按 skillkit 退出 3。转换为 IFCC 是论文预处理步骤，不是臆造的 accept 因子。

## 适用范围和操作选择

正文 2.2 第 5–6 页：此前/当前任一 HbA1c ≥48 mmol/mol（正文标作 ≥6.5%）、空腹血糖 ≥7.0 mmol/L、报告医生诊断或糖尿病用药定义糖尿病；既往发生后后续均按已发生处理。需至少三个月前的一项无糖尿病 HbA1c 测量。基线来自健康访视 4、6、8/9。用户确认这些条件后才可传 `--eligible-baseline 1`；未知、不符合和缺项均不计算。

百分数 6.5 按正文舍入换算式约为 47.54 mmol/mol，与正文括注的 48 不完全一致。接口采取保守的适用性保护：百分数达到 6.5 或换算值达到 48 均拒绝；不把低于 48 的 6.5% 输入放行。此保护不是新诊断规则，也没有修改模型系数。IFCC 低于正文合理性下限 15 也拒绝。

年龄 50–110、访视间隔 0.25–20 年、HbA1c 3–25% 是接口检查范围，不是论文样本极值或疗效阈值。HbA1c 还需通过上述适用性保护；目标值同样检查。访视间隔不在 4–7 年内时额外标出外推。研究原本使用之后观察到的访视间隔而不是前瞻固定期限，本工具的指定间隔是条件情景。ELSA 人群几乎均为白人，不能将模型视为已在中国人群校准。

只有 HbA1c 可作为目标输入。levers.json 写出局部解析导数：`100*p*(1-p)*beta/SD`，HbA1c 再乘 10.929，年数再除以输入年数；二元性别用女性概率减男性概率，不把离散变量当可变治疗目标。资格确认没有敏感度。未传目标时仅输出当前结果和敏感度。

## 复现与缺口

编码前检索了全文图表、S1–S14、作者 v1.0.0。没有完整个人输入的 Model A 印出概率，亦无可下载的逐人预测表。S4 是常数，不是预测示例；Table 3 是逐折模型的队列表现，不能用最终 Model A 加上一个人输入来复现 AUC。

先编写 `test_printed_hba1c_mean_conversion`：Table S1 的百分数均值 5.58、6.13 转回 IFCC 均值 37.5、43.5，绝对容差 0.105，涵盖两列各自舍入误差。该例仅验证预处理，因此 validation 仍为 draft，examples 块明确写 preprocessing only。
其余测试是工程核对：独立转录 S4 参数；按 S2 方程构造解析期望值；检验输入失败、未提供必需信息、目标限制、解析敏感度及旧输出清除。解析式计算出的测试期望**不**声称是论文印出概率。

没有推导未印常数、拟合第三方输出、运行作者完整分析或测外部效度。即使后续找到概率示例，本预印本在同行评审版本出现前仍必须保持 draft。
