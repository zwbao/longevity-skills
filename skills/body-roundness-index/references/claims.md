# 论文证据核对

- 研究设计：原创方法研究，基于成人横断面人体测量、DXA 与 MRI 资料建模和跨数据库验证，并非干预试验；PubMed 23519954 对应原创期刊文章，Wiley 标记 Original Article。
- 全部样本组：正文表 1，NHANES（论文称 NHANES III）男 3281、女 3158，共 6439，用于体脂模型；St. Luke’s/Roosevelt 男 167、女 203，共 370，用于 VAT 模型；Kiel 男 174、女 246，共 420，用于验证及独立比较模型。没有随机对照组。不把三库合并为一个前瞻性验证队列；样本和测量定义沿用论文，未自行修订其 NHANES 命名。
- 物种：人（human / Homo sapiens），本研究没有动物实验。
- 利益冲突：Wiley 声明作者无利益冲突，同时披露 Diana M. Thomas 为 Jenny Craig 顾问；PMC 作者稿亦列出该顾问关系。资金支持列有 NIH/NIDDK 相关资助。
