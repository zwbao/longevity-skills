# 缺陷累积虚弱指数

适用于已有原论文附录项目二元评估计数的老年人。先核对分子、分母来自同一次评估，且缺失项目没有当作正常。研究年龄范围为 65–106 岁；年龄只用于适用范围检查，性别不进公式。

用户命令：

```bash
python3 scripts/personal_report.py --measurements measurements.csv --age 82 --out out
```

测量文件为 `marker,value,unit` 三列。`deficits_count` / 缺陷数和 `assessed_count` / 已评估项数均为整数，单位 `1` 表示计数，无其他单位换算。必须满足 0 ≤ 缺陷数 ≤ 已评估项数 ≤ 92，分母不能为零。每项有缺陷计 1，无缺陷计 0；未评估项不进分母。计数必须已由原始评估记录确认；不能拿加权分数或其他虚弱量表总分代替。

论文没有提供完整的逐项编码字典。尤其不能自行把 ONSET、SINCE、ADL/IADL 或实验室数值转成 0/1。若只有原始化验或病历叙述，先说明缺少二元评估及其计数，不能凑分子和分母。技能附带 [原文变量清单](references/appendix.csv)，这是核对名称的索引，不是自评问卷或临床判定规则。

已有明确假设计数时可加 `--targets targets.csv`，表头相同，可只给缺陷数。保持同一组项目与分母；目标表如提供分母，只允许等于当前值。不得把减少缺陷数自动解释为可行的干预目标，或把分母变化解释为健康改善。`levers.json` 给出 q 对计数的数学敏感度、目标结果和单项变化；不建议改变项目集合。

报告开头保留论文卡片；先报告 q，再报告明确标注为历史探索性模型的 24、60 个月生存概率。q=0 时不报告生存概率，避免把公式退化为 100% 的结果解释为健康保证。不输出诊断切点、预计寿命、年龄等价值或每年衰老速度。

正常输出 `report.md`、`result.json`、`levers.json`；缺项、错单位、超范围、非整数、矛盾计数或非法目标时退出 3，写 `problems.json`，结果为 null。不要向用户索要论文、公开附录或队列数据，这些已经核对。不得从年龄或其他字段估填缺失计数。

每份报告必须保留：

> 边界：本报告仅重算已评估缺陷的比例及原论文探索性生存模型，不能预测你的实际寿命、诊断虚弱或痴呆，也不能据此开始、停止或调整药物；目标情景不是干预效果或延寿承诺。
