## 参数与运算

| 运算所需信息 | 原文位置 | 实现 |
|---|---|---|
| 二元项等权，q = 缺陷数 / 已评估项数；缺失项不进分母 | Methods，324–325页 | `frailty_index` |
| 原始项目集合92项 | Methods及Appendix，324、335–336页 | `MAX_ITEMS=92`；`appendix.csv`名称索引 |
| 临床样本年龄65–106岁 | Methods，324页 | `AGE_RANGE`；超出范围停止，不外推 |
| k=1.456，λ=0.209 | 方程(3)附近，328页 | `GAMMA_SHAPE`、`GAMMA_RATE` |
| P=Γ(k,λqT)/Γ(k)，T单位月 | 方程(4)，328–329页 | 上不完全gamma正则化函数 |
| T=24和60个月 | 329页印刷示例 | 两个固定时间点，不作长期寿命外推 |

原文把λ称为scale，但密度式包含 exp(-λV)，因此计算中它是rate，不能把0.209直接当作常见软件的尺度参数。全部模型常数照原文，不拟合、不反推。标准库实现通过收敛的下不完全gamma级数取补，最大自变量为0.209×60；1e-15只是数值迭代精度，不是模型参数。

q=0时原公式在两个时间点均退化为1，报告以null抑制生存概率并解释原因；q仍报告0。数值上容许所有合法计数，不自创最少项目数的临床切点；每份报告提醒项目少和缺失有偏的限制。比较前后两次评估必须核对同一组项目，仅凭总计数无法由脚本证明其一致性。

## 先写测试的印刷示例

- Methods：从92项中评估80项，12项缺失，16项有缺陷，q=0.2。测试期望值0.2直接来自印刷文本，不由实现生成。
- 329页：q=0.20；24个月，V=4.8，P=0.55；60个月，V=12，P=0.16。测试允许概率绝对误差0.005，符合印至两位小数的精度。未用这两个示例调整任何参数。
- 数学复现仅证明实现与印刷公式相符，不证明该历史生存模型已被临床验证。

## 目标接口

接受与测量同表头的目标计数；分母必须相同。`levers.json`采用longevity-levers/1，包含current、sensitivity、levers及有目标时的targets。q的解析敏感度为1/m（分子）和−d/m²（分母）；分母敏感度只说明缺失／分母影响，不允许作为目标。两项敏感度为局部连续数学导数，输入仍必须是整数。仅有缺陷计数可改变，所以单项目标与全部目标的结果相同；q=0时目标生存概率及其差值为null。没有从指数变化推算药物、运动或营养干预的因果效应。

## 明确不实现

方程(1)的队列分布、方程(2)的跨年龄组回归、方程(5)的诊断组变异系数不属于个人计数读出。表1的组均值不能作为个人确诊阈值。不给加权评分；文末仅讨论加权可能性，未印权重。全92项自动评估缺少异常阈值、ONSET/SINCE编码、ADL/IADL规则，本技能不会以常识补齐。
