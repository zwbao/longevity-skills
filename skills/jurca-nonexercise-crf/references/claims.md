# 原文与实现核对

研究设计：Jurca 等，American Journal of Preventive Medicine，2005，29(3):185–193。三个既有成人样本的横断面二次分析，用多元线性回归建模并跨样本验证；没有以死亡随访为本研究结局，没有随机干预。PubMed PMID 16168867及ScienceDirect元数据标识为原创研究。

全部样本组：NASA 1,863人（男性1,458，女性405）；ACLS 46,190人（男性35,826，女性10,364）；ADNFS 1,706人（男性853，女性853），均为20–70岁。三组合计49,759人。每一组各自建模，并用于另两个模型的验证，不是三组相加共同拟合NASA公式。没有另设病例/对照组。NASA采用最大运动气体分析实测CRF；ACLS按最大跑台工作负荷估计；ADNFS按亚最大测试外推。

物种：人（human / Homo sapiens；原文为men and women）。无动物或细胞实验。
