# 论文主张与实现范围

研究设计：原创测量方法开发和验证（PubMed / Europe PMC 出版类型 Journal Article，非综述）。用美国社区老年人横断面 SFT 数据，结合既有纵向研究及专家判断，提出标准；另作并行效度和重测一致性分析。并非把推导参与者随访到 90 岁的预后研究。

全部样本组：原 SFT 常模数据库 7,183 名 60–94 岁美国老年人；本研究取其中符合年龄调整 CPF 中等功能定义的 2,140 人推导。表 3 七组人数依次为 144、369、538、515、306、180、88，无另设病例或对照组。验证样本共 82 人（女性 48、男性 34），平均年龄 70.2 岁，SD 5.7；能不借助辅助器具行走，且未被医生告知应避免运动。表 5 各测试有效样本分别为 75、69、78、68、73；表 6 重测分别为 73、71、73、69、71，不把 82 当作每项测试样本数。原基线人群主要是白人（89.1%），平均受教育年数 14.5；外推其他人群需验证。

物种：人（human / Humans），没有本文自己的动物或细胞实验。

利益冲突：完整 PDF 未见独立的 Competing interests / Disclosures 声明，不能写成“声明无冲突”。正文和参考文献显示两位作者也著有 Senior Fitness Test Manual；未见明确的专利、雇佣或资助利益说明。Acknowledgments 感谢专家及从业者评审小组，不据此推断存在或不存在商业利益。
