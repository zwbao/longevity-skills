# MoCA 认知筛查计分核对

用户命令：`用我的原版完整 MoCA 分项得分和受教育年限，核对总分与筛查分档。`

先确认记录来自施测人员完成的原版完整 MoCA，分项尚未加入教育校正。需要施测人员给出的任务得分和正式教育年数，字段见 `skill.json`。不得根据症状、聊天答案、绘画图片或答对次数自行评定任务分数。只有总分时，需要补充分项记录，不能反推。

输入为 CSV，表头 `item,value,unit`。任务单位为 `score`，教育年限单位为 `a`（也接受通用单位规范中的“年”和 years）。各任务为整数；未知项目不能填零。中文名称只是录入别名，不是中文版试题或中文版常模。

```bash
python3 scripts/personal_report.py --measurements assessment.csv --out out
```

脚本读取全部任务和教育年限；缺项、单位错误、超范围、小数任务分或无法识别项目均退出 3，写入 `out/problems.json` 和有论文卡片的错误报告。成功时生成 `out/report.md` 与 `out/result.json`，分别列出原始分、实际教育加分、校正总分和原文切点分档。

本技能不需要用户提供全文、补充表、代码或队列数据；依据和访问记录已写在 `references/`。不得把其他 MoCA 版本或未完成测评的分数填入本方法；施测应使用适用版本的官方材料。本技能不分发试题或施测说明。

不要设置分数改善目标或生成 levers；本方法是当前认知筛查计分，不是可改变输入的风险模型。不得把原研究敏感度、特异度或预测值写成这个人的患病概率。分数高于切点不能排除问题，低于切点不能诊断疾病。

报告必须保留论文卡片、研究适用范围与下面的边界句：

边界: 本报告仅核对已完成标准施测的原版完整 MoCA 得分；筛查分档不能诊断或排除轻度认知障碍或痴呆，不能区分两者，也不能预测个人未来痴呆风险、衰老速度或寿命；不能据此开始或停止药物。
