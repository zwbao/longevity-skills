# 产品合同

1. 用户提供自己的过去一年三题回答（明确的选项编码，单位1），可附年龄与性别；数据类型是问卷。
2. 技能内置原文已发表的选项到分数映射及两个切点，离线计算，无需用户找公开材料。
3. 报告只输出逐题分数、总分和与原研究切点的比较，不输出诊断、寿命、个人患病概率或治疗方案。

流水线已授权构建此读出，按用户要求直接执行，不另设合同确认环节。

## 可行性与来源

来源：[Bush 等，1998，JAMA全文](https://jamanetwork.com/journals/jamainternalmedicine/fullarticle/208954)，
DOI 10.1001/archinte.158.16.1789，Archives of internal medicine。
已读正文Methods、Results、Comment及文末说明。计算所需每个常数均在正文：

| 项目 | 正文定位 | 内置值 |
| --- | --- | --- |
| 第一题按原顺序六个选项得分 | Methods / Measures，第一题 | 0、1、2、3、4、4 |
| 第二题按原顺序六个选项得分 | Methods / Measures，第二题 | 0、0、1、2、3、4 |
| 第三题按原顺序五个选项得分 | Methods / Measures，第三题 | 0、1、2、3、4 |
| 合计 | Measures，三题后计分段 | 求和，0–12分 |
| 两个切点 | Results中Table 3附近文字、Comment末段 | ≥3、≥4 |

选项文字见SKILL.md；唯一运行时计分定义在 `scripts/presets.py`。
输入编码从0开始是本地接口约定，不伪装为论文原始编码。
无物理单位转换：不接收酒精克数、每周总量或已经求好的总分替代三题回答。
论文未给统一每杯乙醇克数，不从其他版本借用常数。

## 验证

先写 `tests/test_manifest.py::test_printed_quantity_per_term_scores`，
在实现前运行确认缺少实现而失败，然后实现。其期望值来自正文第二题：
典型饮酒日3–4杯计1分、5–6杯计2分；manifest保留含这两项的短逐字引文。
整数完全相等，无拟合、无舍入容差。另枚举正文全部选项的分数核对两个重复计分选项，
并测试切点等号、缺项、错单位、超范围、非整数、非有限数和问卷回答冲突。
集成测试使用明确标注的合成输入，不称其为论文参与者。

复现范围仅是逐项计分。正文有用假设患病率和似然比计算筛查后概率的演示；
本技能不接受群体患病率，不实现该演示，也不把其结果显示为个人概率。
图表图片访问失败的具体记录见claims.md；不宣称核对表内单元格。
正文已完整印出所有运算常数，因此图表的群体性能单元格不是评分实现的缺失参数。

## 适用性及输入防护

验证样本为美国VA门诊男性饮酒者，非独立外部验证，也非长期结局模型。
两个切点都用于原男性样本；性别不改变分数。非男性或未知性别仅作数值比较并提示适用性。
可选年龄限制18–120岁是产品的成年用户防错范围，并非论文证实的年龄有效范围。
原分析要求过去一年有足够饮酒量进入抽样，不能把零分端点当作非饮酒者的性能验证。
从不饮酒却报告饮酒杯数/六杯频率，或报告饮酒但典型饮酒日为零杯时要求核对，
这是输入一致性检查，不是新增医学阈值。空值不补零，不自动补齐跳题。

不提供 `--targets` 或 `levers.json`：它衡量既往一年回答的筛查信号，
没有可用于推断改变回答后未来健康获益的风险方程或纵向模型。

边界: 这是饮酒问题筛查，不是酒精使用障碍诊断，也不预测寿命或长期风险；原研究验证样本为男性退伍军人，不能把其筛查性能直接推广到女性或其他人群。不能据此开始、停止或调整药物。
