# 研究核查

研究设计：人类年龄组横断面比较，附白天视觉刺激和屏气生理实验；不是随机治疗试验，
也不是个人随访预测模型。Europe PMC（DOI查询，2026-11-24）出版类型为 Journal Article；
PubMed PMID 43026299为2026年正式期刊版，链接到2025年预印本但没有将两者混用。
期刊在线日期为2026-11-13，尚未列卷期，年份统一为2026。
