# 产品合同与计算来源

1. 用户提供自己两份可比 NREM 记录的额叶慢波和全灰质 BOLD 线性功率比，以及两份记录时的年龄；两个比值须使用同一参照记录。
2. 技能维护者已取得期刊全文、全部九份附件和相关公开软件，冻结补充表3的系数；运行时不联网，不要求用户交队列或补表。
3. 报告只算同年龄组、同采集与处理流程下的条件 CSF 功率差；不算绝对功率、流量、废物清除、脑龄、疾病风险或干预获益。

这是流水线授权范围内的窄化实现。使用期刊正式版本 Bailes 等，Nature Aging，2026，
DOI 10.1038/s43587-026-01270-4；不是2025年的预印本。

## 可行性核查

Supplementary Information PDF 第5页 Table 3 是图片表格，已视觉逐项核对。
列为 Path、Effect、Estimate、SE、Lower CI、Upper CI、p-value。
其中 M1→Y 的 b1=0.804、M2→Y 的 b2=0.610；正文 Fig.5 明确
M1=额叶 EEG 慢波功率，M2=灰质 BOLD 功率，Y=CSF 功率，X=年龄组。
Table 2 将 M1/M2 标签交换；遵循正文 Fig.5、Table 3 和 Fig.5 源数据。
Table 3 的中介间路径写 d21，而正文写 d12；两者指同一 M1→M2 方向。
表中无截距，无标准化处理要求；Methods 规定使用各受试者的 dB 带功率。
所有运行时模型斜率均直接来自 Estimate 列，未从源数据拟合参数。

年龄组的具体数值编码未明示：正文只说 categorical，Fig.5 源数据 X 列给的是实际年龄。
因此本技能不实现年龄组项，不把 X 当每岁年龄，不自行猜测编码。
两份记录须属于同一年龄组；此时不论采用何种分类编码，年龄组项严格抵消。

原条件均值模型可写作 `E[Y|X,M1,M2] = intercept + c' X + b1 M1 + b2 M2`。
相同 X 下，模型对比为：

```
delta_EEG_dB  = 10 * log10(EEG_power_comparison / EEG_power_reference)
delta_BOLD_dB = 10 * log10(BOLD_power_comparison / BOLD_power_reference)
delta_CSF_dB  = 0.804 * delta_EEG_dB + 0.610 * delta_BOLD_dB
```

因而没有缺失本计算所需的截距或年龄编码。对数因子10是功率分贝的定义，
不是新拟合的模型常数。输入单位 `1`；`%` 精确乘0.01。
输出 dB 仅表示功率对数比，不是流速的百分比。

比值工程校验范围为[0.001,1000]（允许±30 dB），不是论文临床阈值或正常范围。
取比前每份记录都必须满足相同测量定义；仅同年龄并不能保证设备间校准可比。
输入中不加入体检、性别、现用药等来修改论文斜率。

## 测量定义

取自 Methods “Nighttime experiment: spectral power analysis”、EEG preprocessing、
fMRI preprocessing，以及 Reporting Summary 第4页 Normalization。

- 同步研究级 EEG/fast fMRI；夜间自然睡眠。fMRI TR=0.378 s，3T Prisma，
  2.5 mm各向同性、40层、多带因子8；并非任意日常MRI。
- EEG去除梯度和心搏伪迹，平均参考；额叶 F3/F4/F7/F8/Fz/FT9/FT10。
- NREM连续60秒窗；排除平均位移>0.3 mm、最大位移>0.75 mm的窗；
  EEG排除坏导及绝对振幅>150 µV的窗。
- multitaper：EEG 25 tapers，BOLD/CSF 5 tapers。EEG 0.5–4 Hz带内求和；
  BOLD/CSF 0.01–0.1 Hz带内求均值；按人平均线性带功率后转dB。
- BOLD为全灰质，信号归一至相对均值的百分信号变化；CSF信号归一至第15百分位
  （Reporting Summary）。本技能不从原始序列重做这些步骤。
- 两份记录都是NREM；不能把Fig.3的清醒→睡眠差当成Fig.5中介模型的NREM水平。
  参照是用户真实提供的可比记录，不是自造的年轻人平均、正常值或理想值。

Table 3 提供逐路径乘积，可用同一条件对比计算器复现：

| 印出的输入系数与路径 | 印出的 Estimate | 测试输入的 dB 差 |
|---|---:|---|
| a1=2.178, b1=0.804, indirect1=a1*b1 | 1.751 | EEG=2.178，BOLD=0（隔离EEG项） |

测试以 `10**(dB差/10)` 无损表达相同输入为功率比，未创造独立的期望结果。
零仅用于路径隔离的测试，不用于补齐用户缺失测量。
三位小数系数直接相乘得到1.751112、0.818620、0.49954608；这些是核对过程的
计算值，不是测试期望。期望始终为表3印出的1.751、0.818、0.500。
采用绝对容差0.002 dB，覆盖每个系数±0.0005及输出±0.0005的舍入误差传播。
未反推更精确系数。复现的是逐项数学关系，不是个人纵向预测准确度或独立外部验证。

## 不允许的延伸

不提供总年龄效应预测：跨年龄组时c'项不抵消，编码未印明；不拟合编码或截距。
表3的路径置信区间不等于该人的预测区间；缺少完整误差结构，因此不提供个人区间。
研究是横断面关联；对同一个人两次记录应用方程是条件模型情景比较，不能宣称
实测CSF必然变化或治疗有效。`--targets` 只改变相对原参照的输入比值；
`levers.json` 的 db_per_unit 为对比值的导数，db_per_db 为表3的条件斜率。

边界：这是横断面研究模型在同年龄组、同测量流程下的条件功率对比，不是个人实测脑脊液流量、废物清除效率、脑龄或痴呆风险，也不能预测改善睡眠或任何干预的效果；不能据此开始或停止药物。
