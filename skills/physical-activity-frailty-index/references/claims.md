# 论文、补充材料、代码、同名的另一个东西

- **研究设计**：基于全国代表性队列（CHARLS）的观察性研究；体力活动与衰弱分数是 2011 年基线的横断面分析（线性回归），体力活动、衰弱与 10 年全因死亡是前瞻分析（Kaplan–Meier 和 Cox）。出版类型：原创研究（ORIGINAL ARTICLE）。
- **全部样本组**：CHARLS 2011 基线（表 3 写 6452 人；同表男 3085 + 女 3711 = 6796，原文不一致），限定 60 岁及以上。衰弱表型分析 2231 人（健康 833，衰弱综合征 1398），死亡 859、删失 1372。衰弱指数分析：摘要和表 3 写 2330 人（健康 278，衰弱综合征 2052），方法和生存分析段写 2230 人，死亡 903、删失 1427（903 + 1427 = 2330）。没有独立验证队列。
- **物种**：人（Homo sapiens）。
- **利益冲突**：作者声明没有利益冲突；无资助（Funding: No funding）。
