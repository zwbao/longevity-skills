# 论文、补充材料和代码各写了什么

- **研究设计**：队列研究。CLSA 综合队列基线血样（2012–2015）做全表观组差异甲基化（limma）和方差关联（双重广义线性模型 DGLM）分析，随访约 6 年看全因死亡和五种年龄相关疾病；BLSA 做外部验证（2003–2010 的指数访视，随访到最后已知状态）。Crossref 类型为 journal-article，正文有方法和结果，是原创研究（本次没有核对 PubMed 出版类型）。
- **全部样本组**：CLSA 做了甲基化的 1478 人，质控后 1445 人；主分析为欧洲血统 1284 人（年龄 45–85 岁，正文另一处写 45 到 86 岁，补充表 S1 写 62 (45--86)），按 85%/15% 分成训练集 1091 人、验证集 193 人；验证集死亡分析 187 人、14 人死亡。BLSA 外部验证 728 人、284 人死亡（450K 芯片）。
- **物种**：人（Homo sapiens）。
- **利益冲突**：正文写 L.F.（Luigi Ferrucci）是本刊医学科学部分编委；未声明其他利益冲突。资助：加拿大卫生研究院（PAD 179760）、BC Cancer Foundation、美国 NIH 院内研究项目。

## 摘要和正文的差别

摘要写 448 个差异甲基化区域（DMR）、488 个差异变异区域（DVR）；正文结果写 484 个 DMR（表 S6）、673 个 DVR（表 S10），而 488 是正文里整合标志物保留的 DVP 数。技能不用这些区域数，照正文记录。摘要写年龄 45 到 85 岁，引言写 45 到 86 岁，表 S1 中位数（范围）写 62 (45--86)。

## 仓库里的其他文件（未使用）

`eScores_weights/` 还有 `DMP_450K`、`DVP_450K`（单类位点的对照模型）、`DVP_DMP_v2_450K`，以及 `FI_DMP_450K`、`FI_DVP_450K`、`PF_DMP_450K`、`PF_DVP_450K`。其中 `FI_DVP_450K.csv` 与 `DVP_DMP_v2_450K.csv` 内容逐字节相同，`FI_DMP_450K.csv` 与 `PF_DMP_450K.csv` 只差结果列的标签，`DVP_DMP_v2` 的含义正文和 README 都没有说明。技能只用论文表 S14、S18 对得上的 `DVP_DMP_450K`。
