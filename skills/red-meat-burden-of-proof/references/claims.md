# 证据与实现核对

研究设计：系统综述和非线性荟萃回归，既有观察性研究的二次汇总，没有随机饮食干预，也没有个人预测模型的独立训练/验证队列。Europe PMC出版类型含Systematic Review；检索截止2022-05-10，全文称系统综述未注册。报告及登记年为Nature Medicine卷期2022年。

物种：人（human / Homo sapiens）。没有动物或细胞实验。方法概述为25岁及以上成人；Reporting Summary写至95岁以上，按年龄/地点/性别的分层RR未发表，乳腺癌仅适用于女性。

全部样本组：55份报告来自37个前瞻性队列及1个巢式病例对照研究，共38项研究。总体地理分布为欧洲18个队列及1个巢式病例对照，北美13个队列，亚洲5个，澳大利亚1个。同一队列可能贡献多个结局；下面人数不能相加作为独立总样本量。Supplementary Table 1逐研究列出样本、结局和测量方法，Table 8列暴露组与参照组；没有另招募统一对照组。
