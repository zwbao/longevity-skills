# 论文、补充材料、代码、同名的另一个东西

- 研究设计：多中心、跨洲的观察性队列研究（2015–2024），回顾性汇总前瞻评定的 SARA；横断面分布分析加纵向线性混合效应模型（SAS PROC MIXED）。PubMed/Europe PMC 出版类型为原创研究（Journal Article，PMC13503081）。
- 全部样本组：SCA27B 患者 219 人（女 101、男 118），9 个中心（Tübingen 54、Essen 34、Berlin 21、Munich 12、Lübeck 7、Montreal 44、Strasbourg 26、Nancy 11、Innsbruck 10），661 次评分，116 人有纵向随访；筛查时 366 人（表 S1）。进展模型排除 14 名合并症干扰者（表 S3）。健康对照 390 人（18–79 岁，平均 47.5 ± 17.1 岁），来自独立的 SARA 验证研究和症状前 SCA 自然史研究中的非携带者（Grobe-Einsler 等 2023）。没有单独的验证队列。
- 物种：人（Homo sapiens）。
- 利益冲突：AT、RDH、FE、CDep、TW、CDel、AN、CA、DP、EI、FH、MR、BB 声明无。MB（Bial）、MGE（Biogen、Aparito/Eli Lilly）、JF（Vico、Biogen）、TK（Servier、UCB、BottNeuro、Arrowhead、BMS 等）、LS（Alexion、Reata）、MA（IPSEN、Abbvie、Reata、Biogen 等）、DT（DFG、EU、Bernd Fink 基金会）、MS（Ionis、UCB、Biogen、Reata、Biohaven、Lilly 等多家）报告了顾问费或资助，均声明与本文无关。没有作者与 4-AP 或 SARA 相关的专利声明。

| 论文声称 | SCA27B 的 SARA 严重度主要来自步态、站姿和跟膝胫；健康老人 SARA 变异随年龄增大，使患者与对照的区分（AUC 0.97→0.91）和对症治疗的反应窗口随年龄缩小；排除合并症后全队列进展 0.54 分/年（独立行走亚组 0.40）；较短等位 GAA 重复数是进展修饰因素（每 100 重复 +0.48 分/年；>180 组 +1.6，≥250 组 +3.2）。 |

| 代码实际算什么 | 论文没有公开代码，数据“按合理请求提供”。本技能只做：八项相加；按年龄段查正文印出的中位数和第 90 百分位；按 S4/S5 交互系数乘以与 16 个重复的差。不拟合、不外推到印出范围以外的年龄段。 |
| 同名的另一个东西 | SCA27A 是 FGF14 点突变/缺失引起的另一种早发共济失调，与 GAA 重复扩增的 SCA27B 不同。SARA（Schmitz-Hübsch 2006）是量表本身；fSARA、FARS-E 是论文讨论里提到的其他量表，本技能不算。 |
