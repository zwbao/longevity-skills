# 产品合同与可行性

用户提供同次检查的定量 CRP、中性粒细胞绝对计数和淋巴细胞绝对计数，并注明单位；可选年龄及用户指定的假设值。
技能使用已经核对并冻结的正文公式和补充材料切点，不需要运行时下载队列或要求用户找公共文件。
报告只给出 NLR、IBI 及与论文探索切点的算术对照；不生成 DunedinPACE、衰弱诊断、B3 评分、药物排序或个人风险。

## 来源与每个常数

Wang 等，npj Aging 12:163（2026），DOI 10.1038/s41514-026-00459-6。

| 内容 | 精确出处 | 实现 |

| 年满 50 岁 | Methods, DunedinPACE | 年龄仅提醒外推范围，不改变公式 |

单位换算属于量纲换算：CRP mg/dL → mg/L 乘 10；ug/mL → mg/L 乘 1；细胞 10^3/uL → 10^9/L 乘 1；/uL → 10^9/L 乘 0.001。所有换算由 skillkit 按 manifest 执行。IBI 的 mg/L 单位由 CRP 单位乘无量纲细胞比值得到，并非新定义的生物标志物浓度。

输入范围仅是工程检查，不是临床正常值：CRP 0–1000 mg/L；中性粒 0–200、淋巴 0.001–200（10^9/L）。范围刻意较宽；分母零不可计算。真实检测结果落在范围外时拒绝并要求核对，不截断。小于检测限、百分比和不明确单位不转成精确值。用户须自行确保同次检查，不根据数值推断时间。

## 验证差距与尺度约定

已读全文 HTML/PDF、Table 1、唯一补充 PDF 的 Figures S1–S8 与 File S1，以及作者应用的静态界面。没有印出一组完整 CRP/N/L 输入及其 IBI 输出。Table 1 的 IBI 0.54 是群体中位数，不能用不同指标的中位数相乘来复现；S3D 的斜率与切点不提供个人预测模型截距。Figure S4 可核对分层边界，但它不是连续计算示例。因此 validation=draft，inputs_status=draft。

正文 Methods 明写 CRP mg/L，应用输入也标 mg/L。但 Statistical methods 又称对 FI、IBI、DunedinPACE 标准化后回归；没有公开分析代码供确认切点产生过程。正文 Table 1 总体 IBI 中位数 0.54，与跨周期比较段落中原周期 0.29 不同，未解释两者的分析集或权重差异。S3D 标注原名 IBI，没有标准化转换参数。实现仅按明确印出的原始公式和原名切点作**暂定算术对照**，报告必须显示该尺度尚未独立核实；不猜测 z-score 均值/标准差，不私自把 mg/L 改为 mg/dL，不反推或拟合常数。

先写了 tests/test_manifest.py，然后写实现。测试核对 S4 的等号归属，并使用明确标为合成的 N/L=1 恒等式、单位等价性、错误输入以及假设情景；这些工程检查不能升级验证状态。没有从脚本输出构造论文期望值。要升级为 reproduced，需要带完整输入输出的作者示例或可核对的独立印出计算，而不是应用默认输入。

## 假设情景

--targets 只替换用户明确指定的变量，其余保持当前值；每个单项和联合结果都重算同一公式。局部导数来自已印公式的解析微分：对 CRP 为 N/L，对 N 为 CRP/L，对 L 为 −CRP×N/L²。无新拟合常数。没有建议降低中性粒或升高淋巴，也不把切点称为可追求的目标。

边界：这是探索性炎症指标及论文切点的算术对照，不是衰弱诊断、衰老速度、个人患病概率或治疗目标；不能据此开始或停止药物，也不提供剂量。
